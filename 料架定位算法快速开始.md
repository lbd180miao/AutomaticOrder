## 📋 常用操作

### 1. 单独检测平面（找Z）

```python
from apps.vision.rack_positioning_algorithm import RackPositioningAlgorithm
import numpy as np

algorithm = RackPositioningAlgorithm()

# 支撑面点云
support_plane_cloud = np.array([...])  # shape: (N, 3)

# 执行平面检测
result = algorithm.detect_support_plane(
    pointcloud=support_plane_cloud,
    distance_threshold=2.0,  # RANSAC距离阈值（mm）
    min_inliers=100          # 最小内点数
)

print(f"Z轴位置: {result.z_position:.2f}mm ± {result.z_std:.2f}mm")
print(f"置信度: {result.confidence:.3f}")
print(f"内点数: {result.inliers.shape[0]}")
```

```python
from apps.vision.rack_positioning_service import RackPositioningService
from apps.vision.coordinate_transform import CoordinateTransformService
from apps.dm_camera.services import DMCameraService

# 初始化服务
positioning_service = RackPositioningService()
camera_service = DMCameraService()
transform_service = CoordinateTransformService()

def process_rack_layer(recipe_id, layer_no, robot_pose):
    """
    完整料架定位流程
    
    Args:
        recipe_id: 配方ID
        layer_no: 层号（1, 2, 3...）
        robot_pose: 机器人拍照位姿 [x, y, z, rx, ry, rz]
    
    Returns:
        定位结果
    """
    
    # 步骤1: 3D相机采集点云
    print(f"采集第{layer_no}层点云...")
    pointcloud_camera = camera_service.capture_pointcloud()
    print(f"  ✓ 采集到 {pointcloud_camera.shape[0]} 点")
    
    # 步骤2: 执行定位（服务会自动处理坐标转换和ROI裁剪）
    print(f"执行定位计算...")
    result = positioning_service.process_layer_positioning(
        recipe_id=recipe_id,
        layer_no=layer_no,
        pointcloud=pointcloud_camera,
        robot_pose=robot_pose,
        coordinate_system='CAMERA',  # 相机坐标系
        vision_task_id=123
    )
    
    # 步骤3: 检查结果
    if result.is_success:
        print(f"  ✓ 定位成功")
        print(f"    实际位置: X={result.actual_x:.2f}, Y={result.actual_y:.2f}, Z={result.actual_z:.2f}")
        print(f"    偏移值: ΔX={result.offset_x:.2f}, ΔY={result.offset_y:.2f}, ΔZ={result.offset_z:.2f}")
        print(f"    置信度: X={result.confidence_x:.3f}, Y={result.confidence_y:.3f}, Z={result.confidence_z:.3f}")
        
        # 步骤4: 写入PLC（下一步开发）
        # plc.write_compensation(layer_no, result.offset_x, result.offset_y, result.offset_z)
        
        return result
    else:
        print(f"  ✗ 定位失败: {result.error_message}")
        return None
```

## 💡 最佳实践

### 1. 点云预处理

```python
import numpy as np

def preprocess_pointcloud(pointcloud):
    """点云预处理"""
    
    # 1. 去除NaN和无穷值
    mask = np.isfinite(pointcloud).all(axis=1)
    pointcloud = pointcloud[mask]
    
    # 2. 去除离群点（简单版：3σ原则）
    z_mean = pointcloud[:, 2].mean()
    z_std = pointcloud[:, 2].std()
    mask = np.abs(pointcloud[:, 2] - z_mean) < 3 * z_std
    pointcloud = pointcloud[mask]
    
    # 3. 降采样（可选，加速处理）
    if pointcloud.shape[0] > 5000:
        indices = np.random.choice(
            pointcloud.shape[0], 
            5000, 
            replace=False
        )
        pointcloud = pointcloud[indices]
    
    return pointcloud
```

### 2. 错误处理

```python
def safe_positioning(recipe_id, layer_no, pointcloud):
    """安全的定位流程（带错误处理）"""
    
    try:
        # 预处理
        pointcloud = preprocess_pointcloud(pointcloud)
        
        if pointcloud.shape[0] < 100:
            raise ValueError(f"点云点数过少: {pointcloud.shape[0]}")
        
        # 执行定位
        result = service.process_layer_positioning(
            recipe_id=recipe_id,
            layer_no=layer_no,
            pointcloud=pointcloud,
            coordinate_system='ROBOT'
        )
        
        # 验证结果
        if not result.is_success:
            print(f"定位失败: {result.error_message}")
            return None
        
        # 检查偏移是否过大
        max_offset = 50.0  # mm
        if abs(result.offset_x) > max_offset or \
           abs(result.offset_y) > max_offset or \
           abs(result.offset_z) > max_offset:
            print(f"警告: 偏移值异常大")
            print(f"  ΔX={result.offset_x:.2f}mm")
            print(f"  ΔY={result.offset_y:.2f}mm")
            print(f"  ΔZ={result.offset_z:.2f}mm")
        
        return result
        
    except Exception as e:
        print(f"定位流程异常: {e}")
        import traceback
        traceback.print_exc()
        return None
```

```python
       abs(result.offset_z) > max_offset:

        return False
    
    return True
```

## ❓ 常见问题

### Q1: 如何提高检测精度？

**A**:
1. 增加点云密度（更多点）
2. 调整ROI范围，确保覆盖关键特征
3. 调优算法参数（降低distance_threshold）
4. 进行点云预处理（降噪、离群点去除）

### Q2: 为什么某个轴的置信度很低？

**A**:
1. 该ROI点云点数过少
2. 特征不明显（如边缘不清晰、平面不平）
3. 算法参数不合适
4. 坐标系不一致

### Q3: 如何处理点云为空的情况？

**A**:
```python
if pointcloud.shape[0] == 0:
```

### Q4: 如何集成到生产环境？

**A**:
1. 确保手眼标定配置正确
2. 确保3D ROI配置合理
3. 先使用默认参数测试
4. 根据实际结果调整参数
5. 启用结果保存和历史记录
6. 监控定位稳定性
