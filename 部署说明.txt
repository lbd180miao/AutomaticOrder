【快速部署】

1. 备份文件
   - apps/vision/views.py
   - apps/vision/urls.py

2. 验证修改
   python -m py_compile apps\vision\views.py
   python -m py_compile apps\vision\urls.py

3. 运行测试
   python test_roi_auto_save.py

4. 重启服务
   python manage.py runserver
   # 或生产环境：
   # sudo systemctl restart gunicorn

5. 验证部署
   curl http://localhost:8000/api/rack-location/recipes/1/

【核心功能】

✨ 首次绘制ROI → 自动保存到配方
✨ 再次使用配方 → 自动加载已保存的ROI
✨ 更新ROI → 自动覆盖旧坐标

【验收标准】

✓ 保存结果时，配方的roi_config包含target_roi
✓ 计算时不传ROI，能自动使用已保存的ROI
✓ 日志输出"已保存配方 X 的ROI坐标"
✓ 日志输出"自动加载配方 X 的已保存ROI坐标"

【回滚方案】

如需回滚：
1. 恢复备份文件
   cp apps/vision/views.py.backup apps/vision/views.py
   cp apps/vision/urls.py.backup apps/vision/urls.py
2. 重启服务
