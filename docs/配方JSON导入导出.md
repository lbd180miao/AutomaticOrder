# 2D / 3D 配方 JSON 导入导出

在「视觉配方管理」切换到 2D 泡棉或 3D 料架标签页，在配方卡片点击「导出 JSON」。目标电脑打开对应标签页，点击「导入 JSON」选择文件。

导入创建新配方，同名自动添加后缀；不会覆盖已有配方，也不会改变 PLC 默认配方。导入后核对配置，并根据需要明确选择 PLC 默认配方。

## 2D 泡棉标准的定义

- 左右标准 ROI：人工绘制的矩形或多边形，定义标准泡棉的位置、形状和面积。
- 本层搜索 ROI：查找实际泡棉的范围，不代表标准泡棉的形状。
- 检测参数：分割实际泡棉，并控制覆盖率、完整性、偏移等判定。
- 图像尺寸及标定比例：用于坐标转换和像素/毫米换算。

普通泡棉配方保存 ROI 与参数即可。取图是为了绘制 ROI 和试跑；不从当前检测结果重新定义标准，也不要求保存图片模板。

2D JSON 包含名称、ROI、图像尺寸、阈值、算法参数、标定比例、状态及相关产品布局。排除旧 standard_template_config、模板时间/版本、掩膜路径和图片内容；旧模板图片缺失不影响导出。导入不读取或创建图片文件。

产品位移补偿功能已移除。旧配方中的补偿开关和产品基准区不参与检测；保存或导入导出时清除这些旧参数。

## 3D 配方

包含定位参数、标准位姿、几何模板、普通 ROI 和增强 ROI。相机与手眼标定关联按完整配置匹配，不沿用其他数据库的 ID；无唯一匹配时提示重新选择，不覆盖现场设备或标定记录。

## 格式和校验

导出格式版本为 2，最大 32 MB。兼容版本 1：导入 2D 时忽略旧图片模板和附件并提示，只保留 ROI 与参数。非法数据会报错并回滚新记录。

已加入源码；现有打包 EXE 需要重新构建才能使用新功能。
