# 2D / 3D 配方 JSON 导入导出

在「视觉配方管理」中选择 2D 泡棉或 3D 料架标签页：

- 点击配方卡片上的「导出 JSON」，下载该配方已保存的数据。
- 在目标电脑切换到对应标签页，点击「导入 JSON」，选择导出的文件。
- 导入创建新记录；同名自动添加「（导入1）」等后缀，不覆盖现有配方，不改变 PLC 默认配方。
- 导入后核对参数。如需自动运行，在页面中明确选择 PLC 默认配方。

2D 文件包含 ROI、阈值、算法、标准模板信息、被引用的标准模板图片及产品布局。3D 文件包含定位参数、标准位姿、几何模板、普通 ROI 和增强 ROI。不会导出整套历史采集目录。文件最大 32 MB。

相机配置和手眼标定关联按完整配置匹配，不使用来源电脑的数据库 ID；目标电脑没有唯一匹配时，导入仍保留配方参数并提示重新选择关联。不会创建或覆盖现场设备及标定记录。

格式带有类型和版本标识，仅接受本功能导出的版本 1 JSON。类型不匹配、缺失模板或不合法字段会报错。导入失败时回滚新记录和写入的模板文件。

此功能已加入源码；现有打包 EXE 需要重新构建后才包含新接口。
