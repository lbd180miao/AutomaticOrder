## 1. 通讯基础配置

| 项目 | 配置 |
| --- | --- |
| 协议 | S7 TCP/IP |
| PLC IP | 192.168.222.10 |
| Rack / Slot | 0 / 1 |
| 数据块 | 全部使用 DB2 |
| 访问方式 | 取消 DB2 的“优化的块访问”，编译并下载 |
| 读取方式 | 串行读取，每次读取结束后至少间隔 500 ms，不同时轮询多个工序 |
| 新增字段 | DBX74.5：3D拍照完成；DBX74.6：2D拍照完成；DBW76：料框类型代码。全部位于 DB2，至少 78 字节 |

## 3. 本阶段业务流程

1. **料框到位**：读料框码；暂时写死 `INN010144 → 2LayerRack → DBW76=1`。不做已有绑定查询和清空操作。
2. **3D 定位**：调用“南京工厂”3D 配方。点云采集成功后置 74.5，PLC 可以离开拍照位；随后计算补偿并写 DB，最后置 49.1。PLC 到使用补偿的步骤再读取。缺第二组三项时写 0，计算失败六项写 999 并记录报警。
3. **单件条码**：读产品条码，按“料框码 + 产品条码”本地保存，返回读取完成；调用 MES 绑定接口，再返回可装箱。MES 离线或失败时，本地保存成功仍允许装箱，MES 结果保持失败。
4. **泡棉检测**：调用“南京工厂”2D 配方，拍照约 1 秒。图像采集成功置 74.6，PLC 即可移动；检测结果稍后写 74.1，最后置 74.0。PLC 在下一件放行或本框结束前读取；不合格报警并锁站。
5. **循环**：按泡棉配方数量执行单件条码与泡棉检测。需要换层时先执行该层 3D 定位。
6. **封箱上传**：PLC 触发，上位机调用 MES 封箱接口，反馈上传结果，保存区位号；失败时保留本地数据并显示待上传。

46.1 / 48.7 配方校验点位保留，本阶段不单独安排配方校验工序。暂不展开自动补传、断电恢复和复杂重试策略。

## 4. 相机简化时序

**PLC 触发 → 相机拍完通知 → PLC 清触发并移动 → 算法算完直接写 DB → PLC 需要结果时再读。**

| 相机 | 拍完可以走 | 结果已写入 | 结果 |
| --- | --- | --- | --- |
| 3D | DB2.DBX74.5 | DB2.DBX49.1 | 49.2 + DBD50～70 六项补偿 |
| 2D | DB2.DBX74.6 | DB2.DBX74.0 | 74.1 合格 / 不合格 |

上位机接受新请求时清本相机的拍照完成位和结果更新位，拍完再置拍照完成。PLC 看到本次拍照完成位先为 0 再变 1 后即可走，不需再等一轮复位。结果写完后保留，直到下一次请求。

约 1 秒不是从 PLC 触发开始的固定放行定时，移动仍以采集成功反馈为准。每台相机上一件结果读走后再发下一次请求；结果没算好时，只在必须用到结果的步骤等待。采集失败报警并锁站，不发拍照成功完成。
