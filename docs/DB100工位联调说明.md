# DB100 装箱工位联调说明

## 边界

- `devices` 只负责 DB100 地址、S7 编解码和连接。
- `workflow.station_service` 只负责触发/确认握手、状态持久化和跨模块编排。
- `mes` 继续负责配方查询、绑定、装箱结果和请求审计。
- `vision` 提供 2D 料架层高/层距算法；手动调试与 PLC 自动触发复用同一服务。
- `alarms` 负责报警闭环；关闭锁站报警时同步清 DB100 偏移 126。

## BOOL 地址约定

需求表中的 BOOL“偏移 24”按 `DB100.DBX24.0` 解释，即每个 BOOL 使用对应
字节的 bit 0。PLC 侧若实际采用紧凑位布局，必须先修改
`apps/devices/plc_db100.py` 中对应点位的 `offset/bit`，不能直接联机。

`STRING[20]` 使用 Siemens S7 字符串格式：最大长度、当前长度两个头字节加
20 字节内容，总长 22 字节。INT 与 REAL 均使用 S7 大端字节序。

## 运行

```powershell
python manage.py migrate
python manage.py run_workflow_worker --interval 0.2
```

PLC 连接参数在“系统设置 → PLC 点位配置”中维护。真实模式需要：

```text
USE_SIMULATED_DEVICES=0
MES_BASE_URL=http://mes-host:port/
VISION_POSITION_RECIPE_ID=<3D定位配方主键，可选>
RECIPE_MEASUREMENT_CALLABLE=apps.vision.rack_measurement.measure_rack_recipe
```

`python-snap7 3.1.2` 已加入依赖。S7-1200/1500 需在 TIA Portal 允许 PUT/GET，
DB100 需关闭优化块访问，并保证上位机读写账号和现场网络策略允许访问。

`RECIPE_MEASUREMENT_CALLABLE` 是现有 2D 层高/层距算法的适配入口，签名为
`callable(product=..., rack=..., recipe=...)`，返回
`(measured_layer_height, measured_layer_spacing)` 或包含同名键的字典。
这样算法仍留在视觉模块，流程层不复制或修改视觉实现。

项目默认已配置 `apps.vision.rack_measurement.measure_rack_recipe`。打开
`/mes/records/` 的“料架层高层距调试”区，可上传现场图片或手动调用相机，
设置 ROI、毫米/像素标定、边缘阈值后计算层数、层高和层距。确认结果后点击
“保存为自动参数”，PLC 的 `DB100.DBX50.0` 触发将使用该参数自动拍照计算。

手动调试是旁路操作：会保存测量记录和标注图，但不会写 DB100，也不会推进
`StationCycle`。只有工作流收到 PLC 触发时才写 `DBX51.0` 与 `DBX52.0`。

## 无硬件全链路联调

以下命令使用字节级内存 PLC、模拟 MES 和现有视觉服务的模拟模式，实际执行
所有握手、数据库落库、MES 审计、数量循环与满箱判断：

```powershell
python manage.py simulate_db100_cycle --quantity 2
```

它会创建联调生产记录。若要指定条码：

```powershell
python manage.py simulate_db100_cycle `
  --product-code SIM-P-001 --rack-code SIM-R-001 --quantity 2
```

## 握手与幂等

每个触发都执行同一模式：

1. PLC 将触发置 1。
2. 上位机只在对应等待阶段处理一次，写结果和完成位。
3. 上位机持久化 `StationCycle.phase`；进程重启后仍不会重复处理高电平。
4. PLC 清触发。
5. 上位机清结果/完成位并进入下一等待阶段。

MES 装箱上传后不会立即用旧数量判满；系统等待偏移 123 清零，再读取偏移
128。数量达到 MES `total_quantity` 才结束，否则返回泡棉检测循环。

## 现场验收顺序

1. 断开机器人动作，仅核对 DB100 STRING、INT、REAL 和 BOOL 的在线监视值。
2. 验证 16 个 REAL 在 PLC 中的行列顺序与上位机矩阵一致。
3. 对每组触发做“保持高电平 5 秒”测试，确认 MES/视觉只执行一次。
4. 分别注入配方超差、泡棉 NG、MES 失败，确认偏移 126 锁站且报警可追溯。
5. 报警关闭后确认 PLC 偏移 126 清零，并从失败步骤重新触发。
6. 最后开放机器人自动动作，做空框、小数量配方和完整配方三轮试生产。
