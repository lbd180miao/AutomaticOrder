## 方案2：改进判定逻辑

### 🎯 优化目标

从"一刀切"判定改为"智能分级"判定，引入容错机制。

### 📐 设计思路

#### 双阈值判定法

```
硬阈值（Hard Threshold）：20%
  - 任何一侧低于此值 → 不合格（Critical）
  
软阈值（Soft Threshold）：60%
  - 两侧都达到此值 → 合格（Excellent）
  
灰度区间（20%-60%）：
  - 综合评估，容错判定
```

#### 判定逻辑流程图

```
                开始检测
                   |
        ┌──────────┴──────────┐
        |                     |
    检测左侧              检测右侧
     覆盖率                覆盖率
        |                     |
        └──────────┬──────────┘
                   |
          ┌────────┴────────┐
          | 任一侧 < 20%?   |
          └────────┬────────┘
              是 / | \ 否
               /   |   \
        不合格     |    继续判定
      (Critical)   |
                   |
          ┌────────┴────────┐
          | 两侧都 ≥ 60%?   |
          └────────┬────────┘
              是 / | \ 否
               /   |   \
          合格     |    进入灰度区
       (Excellent) |
                   |
          ┌────────┴────────────┐
          | 一侧≥60% 另一侧≥20%? |
          └────────┬────────────┘
              是 / | \ 否
               /   |   \
       合格(Warning) |    检查平均值
                     |
            ┌────────┴────────┐
            | 平均值 ≥ 50%?   |
            └────────┬────────┘
                是 / | \ 否
                 /   |   \
         合格(Info)  |   不合格
                     |  (Major)
```


### 💻 代码实现

#### 步骤1：新增智能判定函数

在 `apps/vision/algorithms/foam_inspector.py` 中添加：

```python
def _intelligent_judgment(left_result, right_result, cfg):
    """智能判定：双阈值+容错机制
    
    Args:
        left_result: 左侧检测结果字典
        right_result: 右侧检测结果字典
        cfg: 配置字典
    
    Returns:
        dict: 判定结果
            - is_passed: bool 是否合格
            - reason: str 判定原因
            - severity: str 严重程度 ('none'|'info'|'warning'|'major'|'critical')
            - details: dict 详细信息
    """
    # 获取配置
    hard_threshold = float(cfg.get('hard_coverage_threshold', 0.20))  # 20%
    soft_threshold = float(cfg.get('soft_coverage_threshold', 0.60))  # 60%
    avg_threshold = float(cfg.get('avg_coverage_threshold', 0.50))    # 50%
    
    left_cov = left_result['coverage_ratio']
    right_cov = right_result['coverage_ratio']
    avg_cov = (left_cov + right_cov) / 2
    min_cov = min(left_cov, right_cov)
    max_cov = max(left_cov, right_cov)
    
    # 场景1：任何一侧严重不足 → 不合格（Critical）
    if min_cov < hard_threshold:
        worse_side = 'left' if left_cov < right_cov else 'right'
        return {
            'is_passed': False,
            'reason': 'severe_deficiency',
            'severity': 'critical',
            'message': f'{worse_side}侧泡棉严重不足（{min_cov:.1%} < {hard_threshold:.0%}）',
            'details': {
                'left_coverage': left_cov,
                'right_coverage': right_cov,
                'min_coverage': min_cov,
                'threshold': hard_threshold,
            }
        }
    
    # 场景2：两侧都优秀 → 合格（Excellent）
    if left_cov >= soft_threshold and right_cov >= soft_threshold:
        return {
            'is_passed': True,
            'reason': 'both_sides_excellent',
            'severity': 'none',
            'message': f'两侧泡棉均优秀（左{left_cov:.1%}，右{right_cov:.1%}）',
            'details': {
                'left_coverage': left_cov,
                'right_coverage': right_cov,
                'avg_coverage': avg_cov,
            }
        }
    
    # 场景3：一侧优秀，另一侧及格 → 有条件合格（Warning）
    if max_cov >= soft_threshold and min_cov >= hard_threshold:
        worse_side = 'left' if left_cov < right_cov else 'right'
        worse_cov = min_cov
        return {
            'is_passed': True,
            'reason': 'one_side_excellent_compensate',
            'severity': 'warning',
            'message': f'{worse_side}侧泡棉略显不足（{worse_cov:.1%}），但另一侧优秀',
            'details': {
                'left_coverage': left_cov,
                'right_coverage': right_cov,
                'compensated': True,
            }
        }
    
    # 场景4：两侧都及格但不理想 → 看综合得分（Info）
    if avg_cov >= avg_threshold and min_cov >= hard_threshold:
        return {
            'is_passed': True,
            'reason': 'average_acceptable',
            'severity': 'info',
            'message': f'两侧泡棉综合达标（平均{avg_cov:.1%}）',
            'details': {
                'left_coverage': left_cov,
                'right_coverage': right_cov,
                'avg_coverage': avg_cov,
            }
        }
    
    # 场景5：其他情况 → 不合格（Major）
    return {
        'is_passed': False,
        'reason': 'insufficient_coverage',
        'severity': 'major',
        'message': f'泡棉覆盖率不足（左{left_cov:.1%}，右{right_cov:.1%}）',
        'details': {
            'left_coverage': left_cov,
            'right_coverage': right_cov,
            'avg_coverage': avg_cov,
            'min_coverage': min_cov,
        }
    }
```

置信度 = f(覆盖率距离阈值的远近, 图像质量, 检测一致性)

高置信度（0.9+）：
  - 覆盖率远超阈值（>150%）
  - 图像质量优秀
  - 左右两侧一致

中置信度（0.7-0.9）：
  - 覆盖率略超阈值（100%-150%）
  - 图像质量良好
  
低置信度（<0.7）：
  - 覆盖率接近阈值（80%-100%）
  - 图像质量一般
  - 左右两侧差异大

在 `apps/vision/algorithms/foam_inspector.py` 中添加：

```python
def _calculate_confidence(left_result, right_result, cfg):
    """计算检测置信度
    
    Args:
        left_result: 左侧检测结果
        right_result: 右侧检测结果
        cfg: 配置字典
    
    Returns:
        dict: 置信度评估结果
            - confidence: float 置信度分数 [0.0, 1.0]
            - confidence_level: str 置信度等级 ('high'|'medium'|'low')
            - factors: dict 影响因素详情
    """
    threshold = float(cfg.get('soft_coverage_threshold', 0.60))
    
    left_cov = left_result.get('coverage_ratio', 0)
    right_cov = right_result.get('coverage_ratio', 0)
    avg_cov = (left_cov + right_cov) / 2
    
    # 因素1：覆盖率相对阈值的距离（权重40%）
    coverage_ratio_score = min(avg_cov / threshold, 1.5) / 1.5
    if avg_cov >= threshold * 1.5:
        coverage_score = 0.95  # 远超阈值
    elif avg_cov >= threshold * 1.2:
        coverage_score = 0.85  # 明显超过
    elif avg_cov >= threshold:
        coverage_score = 0.70  # 刚好达标
    else:
        coverage_score = avg_cov / threshold  # 未达标
    
    # 因素2：左右一致性（权重30%）
    consistency = 1.0 - abs(left_cov - right_cov) / max(left_cov, right_cov, 0.01)
    consistency_score = consistency
    
    # 因素3：图像质量（权重20%）
    image_quality = left_result.get('image_quality', 0.8)
    quality_score = image_quality
    
    # 因素4：检测稳定性（权重10%）
    # 如果检测到的泡棉形状规则，稳定性高
    left_compact = left_result.get('compactness', 0.8)
    right_compact = right_result.get('compactness', 0.8)
    stability_score = (left_compact + right_compact) / 2
    
    # 加权计算总置信度
    confidence = (
        coverage_score * 0.40 +
        consistency_score * 0.30 +
        quality_score * 0.20 +
        stability_score * 0.10
    )
    
    # 置信度等级
    if confidence >= 0.85:
        level = 'high'
        description = '高置信度：检测结果非常可靠'
    elif confidence >= 0.70:
        level = 'medium'
        description = '中等置信度：检测结果基本可靠'
    else:
        level = 'low'
        description = '低置信度：建议人工复核'
    
    return {
        'confidence': round(confidence, 3),
        'confidence_level': level,
        'confidence_description': description,
        'factors': {
            'coverage_score': round(coverage_score, 3),
            'consistency_score': round(consistency_score, 3),
            'quality_score': round(quality_score, 3),
            'stability_score': round(stability_score, 3),
        }
    }
```

### Q2: 容错机制会不会导致放水太多，让不合格产品通过？

**A**: 不会，我们设计了**双阈值保护**：

```

容错只在20%-60%灰度区间生效：
- 一侧78%优秀 + 另一侧35.7%及格 → 合格但警告
- 两侧都30%勉强及格 → 看平均值（需≥50%）
- 任何一侧<20% → 不合格，无容错
```

**更严格的质量控制**：
- 增加置信度评分，低置信度会标记"建议人工复核"
- 判定原因和严重程度更清晰（5个等级：none/info/warning/major/critical）
