# 2D泡棉检测模块技术文档

## 1. 模块概述

### 1.1 功能定位
2D泡棉检测模块是自动化生产线中的关键质量检测环节，专门用于检测汽车保险杠表面贴附的白色泡棉质量。该模块通过高精度工业相机采集图像，运用多种图像处理算法进行智能分析，实现对泡棉贴附质量的实时、准确、自动化检测。

### 1.2 应用场景
- **检测对象**：汽车保险杠表面贴附的白色泡棉
- **相机配置**：海康威视 MV-CS050-10GC（500万像素，10GigE接口）
- **安装方式**：固定俯视安装，覆盖保险杠贴附区域
- **触发机制**：装箱机器人完成泡棉贴附动作后，PLC触发相机拍照

### 1.3 判定规则
模块采用三维评价体系进行综合判定：

1. **泡棉存在性判定** (`is_present`)
   - 检测视野内是否存在白色泡棉
   - 基于颜色特征和形态学特征综合判断

2. **覆盖率判定** (`is_passed`)
   - 泡棉覆盖率必须 ≥ 8%（可配置）
   - 覆盖率不足视为贴附不良

3. **位置对齐判定** (`is_aligned`)
   - 检测泡棉中心相对于ROI中心的偏移
   - 超过阈值视为位置偏移

4. **边缘起翘判定** (`has_lifted_edge`)
   - 检测泡棉边缘是否翘起
   - 基于边缘轮廓和凸包分析

### 2.1 核心算法类：FoamInspector

**文件位置**：`apps/vision/algorithms/foam_inspector.py`（1714行）

**主要职责**：
- 图像预处理与质量评估
- 多策略白色区域检测
- 形态学处理与轮廓提取
- 泡棉质量评价与结果标注

**核心方法**：
```python
class FoamInspector:

```

### 3.1 图像质量分析算法

**目的**：在检测前评估图像质量，为参数自适应调整提供依据。

**分析维度**：

#### 3.1.1 亮度分析
```python
def _analyze_image_quality(self, image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    mean_brightness = np.mean(gray)
    
    # 判定亮度等级
    if mean_brightness < 80:
        brightness_level = 'dark'      # 偏暗
    elif mean_brightness > 180:
        brightness_level = 'bright'    # 偏亮
    else:
        brightness_level = 'normal'    # 正常
```

#### 3.1.2 对比度分析
```python
    contrast = np.std(gray)  # 使用标准差衡量对比度
    
    if contrast < 30:
        contrast_level = 'low'      # 对比度低
    elif contrast > 60:
        contrast_level = 'high'     # 对比度高
    else:
        contrast_level = 'normal'   # 对比度正常
```

#### 3.1.3 清晰度分析（基于Laplacian方差）
```python
    laplacian = cv2.Laplacian(gray, cv2.CV_64F)
    sharpness = laplacian.var()  # Laplacian方差越大，图像越清晰
    
    if sharpness < 50:
        sharpness_level = 'blurry'  # 模糊
    elif sharpness > 150:
        sharpness_level = 'sharp'   # 清晰
    else:
        sharpness_level = 'normal'  # 正常
```

#### 3.1.4 噪声分析（基于高频分量）
```python
    # 高通滤波提取高频分量
    kernel_size = 5
    blurred = cv2.GaussianBlur(gray, (kernel_size, kernel_size), 0)
    high_freq = cv2.absdiff(gray, blurred)
    noise_level = np.mean(high_freq)
    
    if noise_level < 5:
        noise = 'low'       # 噪声低
    elif noise_level > 15:
        noise = 'high'      # 噪声高
    else:
```

### 3.2 自适应参数调整算法

根据图像质量分析结果，动态调整检测参数，提高鲁棒性。

**调整策略**：

```python
def _apply_image_quality_adjustments(self, cfg, quality):
    adjusted_cfg = cfg.copy()
    
    # 1. 根据亮度调整阈值
    if quality['brightness_level'] == 'dark':
        # 偏暗图像，降低阈值以便检测出更多白色区域
        adjusted_cfg['gray_threshold'] = max(150, cfg.get('gray_threshold', 180) - 30)
    elif quality['brightness_level'] == 'bright':
        # 偏亮图像，提高阈值以避免过度检测
        adjusted_cfg['gray_threshold'] = min(220, cfg.get('gray_threshold', 180) + 20)
    
    # 2. 根据对比度调整形态学核大小
    if quality['contrast_level'] == 'low':
        # 对比度低，增大形态学核以连接更多断裂区域
        adjusted_cfg['morph_kernel_size'] = min(9, cfg.get('morph_kernel_size', 5) + 2)
    elif quality['contrast_level'] == 'high':
        # 对比度高，可以使用较小的核
        adjusted_cfg['morph_kernel_size'] = max(3, cfg.get('morph_kernel_size', 5) - 1)
    
    # 3. 根据噪声调整开运算强度
    if quality['noise'] == 'high':
        # 噪声高，增强开运算以去除噪点
        adjusted_cfg['opening_iterations'] = min(3, cfg.get('opening_iterations', 1) + 1)
    elif quality['noise'] == 'low':
        # 噪声低，可以减少开运算以保留更多细节
        adjusted_cfg['opening_iterations'] = max(1, cfg.get('opening_iterations', 1))
    
    # 4. 根据清晰度调整最小面积阈值
    if quality['sharpness_level'] == 'blurry':
        # 图像模糊，放宽面积阈值
        adjusted_cfg['min_area'] = max(50, cfg.get('min_area', 100) - 30)
    
    return adjusted_cfg
```

### 3.3 多策略白色区域检测算法

**核心思想**：采用多种互补的检测策略，通过逻辑OR组合，最大化检测覆盖率，减少漏检。

#### 3.3.1 策略1：HSV色彩空间检测

**原理**：HSV空间中，白色的特点是**高V（明度）、低S（饱和度）**。

```python
# 转换到HSV色彩空间
hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

# 白色HSV范围
lower_white_hsv = np.array([0, 0, 180])      # H任意, S低, V高
upper_white_hsv = np.array([180, 55, 255])   # H任意, S低, V高

# 二值化掩膜
mask_hsv = cv2.inRange(hsv, lower_white_hsv, upper_white_hsv)
```

**优点**：对光照变化具有一定鲁棒性  
**缺点**：在极端光照下可能漏检

#### 3.3.2 策略2：LAB色彩空间检测

**原理**：LAB空间中，白色的特点是**高L（亮度）、a和b接近中性（128左右）**。

```python
# 转换到LAB色彩空间
lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)

# 白色LAB范围
lower_white_lab = np.array([180, 0, 0])      # L高, a和b接近中性
upper_white_lab = np.array([255, 145, 145])

# 二值化掩膜
mask_lab = cv2.inRange(lab, lower_white_lab, upper_white_lab)
```

**优点**：LAB空间更符合人眼感知，对颜色变化敏感  
**缺点**：在强反光区域可能过度检测

#### 3.3.3 策略3：灰度图OTSU自适应阈值

**原理**：OTSU算法自动寻找最优阈值，将图像分为前景和背景。

```python
# 转换为灰度图
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# OTSU自适应阈值
_, mask_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

**优点**：自适应，不依赖固定阈值  
**缺点**：在背景复杂时可能失效

#### 3.3.4 策略4：固定高阈值检测

**原理**：直接使用高阈值（如180）二值化，检测最亮的白色区域。

```python
# 固定阈值（可配置）
threshold = cfg.get('gray_threshold', 180)
_, mask_gray = cv2.threshold(gray, threshold, 255, cv2.THRESH_BINARY)
```

**优点**：简单快速，适用于高亮泡棉  
**缺点**：固定阈值可能不适应所有光照条件

#### 3.3.5 策略5：自适应阈值检测

**原理**：基于局部邻域计算阈值，适应局部光照变化。

```python
# 自适应阈值（高斯加权）
mask_adaptive = cv2.adaptiveThreshold(
    gray, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    blockSize=15,  # 邻域大小
    C=-5           # 常数偏移
)
```

**优点**：适应局部光照变化，适用于不均匀照明  
**缺点**：计算量较大，可能引入噪声

#### 3.3.6 掩膜融合

将五种策略的掩膜通过**逻辑OR**组合，取并集：

```python
# 掩膜融合（逻辑OR）
combined_mask = cv2.bitwise_or(mask_hsv, mask_lab)
combined_mask = cv2.bitwise_or(combined_mask, mask_otsu)
combined_mask = cv2.bitwise_or(combined_mask, mask_gray)
combined_mask = cv2.bitwise_or(combined_mask, mask_adaptive)
```

**效果**：最大化检测覆盖率，减少漏检风险。

### 3.4 形态学处理算法

**目的**：消除噪声、连接断裂区域、平滑边界。

**三步处理流程**：

#### 3.4.1 第一步：闭运算（连接断裂区域）

```python
kernel_size = cfg.get('morph_kernel_size', 5)
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (kernel_size, kernel_size))

# 闭运算 = 先膨胀后腐蚀
mask_closed = cv2.morphologyEx(combined_mask, cv2.MORPH_CLOSE, kernel, iterations=2)
```

**效果**：
- 连接断裂的泡棉区域
- 填充小孔洞
- 平滑凹陷边界

#### 3.4.2 第二步：开运算（去除噪声）

```python
opening_iterations = cfg.get('opening_iterations', 1)

# 开运算 = 先腐蚀后膨胀
mask_opened = cv2.morphologyEx(mask_closed, cv2.MORPH_OPEN, kernel, iterations=opening_iterations)
```

**效果**：
- 去除小噪声点
- 断开窄连接
- 分离粘连物体

#### 3.4.3 第三步：再次闭运算（平滑边界）

```python
# 再次闭运算，进一步平滑边界
mask_final = cv2.morphologyEx(mask_opened, cv2.MORPH_CLOSE, kernel, iterations=1)
```

**效果**：
- 最终平滑边界
- 保持整体形状

**三步处理的必要性**：
- 单次形态学操作无法同时兼顾连接、去噪和平滑
- 三步流程确保检测结果既连续又干净

### 3.5 轮廓检测与过滤算法

**目的**：从二值掩膜中提取泡棉轮廓，并通过多重过滤去除误检。

#### 3.5.1 轮廓提取

```python
# 查找所有轮廓
contours, _ = cv2.findContours(mask_final, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
```

**参数说明**：
- `cv2.RETR_EXTERNAL`：只提取外轮廓，忽略内部嵌套
- `cv2.CHAIN_APPROX_SIMPLE`：压缩轮廓，只保留关键点

#### 3.5.2 三重过滤机制

**过滤器1：面积过滤**
```python
min_area = cfg.get('min_area', 100)

valid_contours = []
for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < min_area:
        continue  # 过滤掉面积过小的轮廓（噪声）
    
    # 继续其他过滤...
```

**过滤器2：宽高比过滤**
```python
    x, y, w, h = cv2.boundingRect(cnt)
    aspect_ratio = float(w) / h
    
    # 过滤掉过于狭长或扁平的轮廓（可能是边缘误检）
    if aspect_ratio < 0.1 or aspect_ratio > 10:
        continue
```

**过滤器3：紧凑度过滤**
```python
    perimeter = cv2.arcLength(cnt, True)
    
    # 紧凑度 = 周长² / 面积（越小越紧凑，圆形约为12.57）
    compactness = (perimeter * perimeter) / area if area > 0 else 999
    
    max_compactness = cfg.get('max_compactness', 50)
    if compactness > max_compactness:
        continue  # 过滤掉过于不规则的轮廓
    
    valid_contours.append(cnt)
```

**过滤效果**：
- 面积过滤：去除噪声点
- 宽高比过滤：去除边缘线误检
- 紧凑度过滤：去除不规则碎片

### 3.6 泡棉质量评价算法

对检测到的泡棉进行多维度质量评价。

#### 3.6.1 覆盖率计算

```python
# ROI总面积
roi_area = roi_width * roi_height

# 泡棉总面积（所有有效轮廓面积之和）
foam_area = sum([cv2.contourArea(cnt) for cnt in valid_contours])

# 覆盖率
coverage_ratio = foam_area / roi_area

# 判定
coverage_threshold = cfg.get('coverage_threshold', 0.08)  # 默认8%
is_present = coverage_ratio >= coverage_threshold
```

**说明**：
- 默认阈值8%已针对大ROI场景优化
- 可在配方中调整 `coverage_threshold` 参数

#### 3.6.2 位置偏移计算

```python
# 计算泡棉中心
M = cv2.moments(largest_contour)  # 使用面积最大的轮廓
if M['m00'] > 0:
    cx = int(M['m10'] / M['m00'])  # 质心X坐标
    cy = int(M['m01'] / M['m00'])  # 质心Y坐标

# ROI中心
roi_cx = roi_x + roi_width / 2
roi_cy = roi_y + roi_height / 2

# 像素偏移
offset_x_px = cx - roi_cx
offset_y_px = cy - roi_cy

# 转换为毫米（如果已标定）
mm_per_pixel_x = cfg.get('mm_per_pixel_x', 0)
mm_per_pixel_y = cfg.get('mm_per_pixel_y', 0)

offset_x_mm = offset_x_px * mm_per_pixel_x if mm_per_pixel_x > 0 else 0.0
offset_y_mm = offset_y_px * mm_per_pixel_y if mm_per_pixel_y > 0 else 0.0

# 判定对齐
max_offset_px = cfg.get('max_offset_px', 30)
is_aligned = (abs(offset_x_px) <= max_offset_px and abs(offset_y_px) <= max_offset_px)
```

#### 3.6.3 边缘起翘检测

```python
# 计算轮廓的凸包
hull = cv2.convexHull(largest_contour)

# 凸包面积
hull_area = cv2.contourArea(hull)

# 实际轮廓面积
contour_area = cv2.contourArea(largest_contour)

# 凸性缺陷率 = (凸包面积 - 轮廓面积) / 凸包面积
convexity_defect_ratio = (hull_area - contour_area) / hull_area if hull_area > 0 else 0

# 判定起翘
defect_threshold = cfg.get('convexity_defect_threshold', 0.15)  # 默认15%
has_lifted_edge = convexity_defect_ratio > defect_threshold
```

**原理**：
- 凸包是包含轮廓的最小凸多边形
- 如果泡棉边缘起翘，轮廓会有明显凹陷
- 凹陷越大，凸性缺陷率越高

#### 3.6.4 综合判定

```python
# 最终判定：泡棉存在 且 覆盖率达标 且 位置对齐 且 无边缘起翘
is_passed = is_present and coverage_ratio >= coverage_threshold and is_aligned and not has_lifted_edge
```

## 4. 结果标注与可视化

### 4.1 图像标注算法

**文件位置**：`apps/vision/algorithms/image_io.py`

**主要函数**：`annotate_foam()`

**标注内容**：
1. **ROI边框**：绿色矩形框标注检测区域
2. **泡棉轮廓**：青色轮廓线勾勒泡棉形状
3. **泡棉中心**：红色十字标记质心位置
4. **判定标签**：
   - ✓ PASS（绿色）/ ✗ FAIL（红色）
   - 覆盖率百分比
   - 偏移量（像素/毫米）

**示例代码**：
```python
def annotate_foam(image, result_data):
    annotated = image.copy()
    
    # 1. 绘制ROI边框
    cv2.rectangle(annotated, (roi_x, roi_y), (roi_x + roi_w, roi_y + roi_h), 
                  color=(0, 255, 0), thickness=2)
    
    # 2. 绘制泡棉轮廓
    cv2.drawContours(annotated, valid_contours, -1, color=(255, 255, 0), thickness=2)
    
    # 3. 绘制泡棉中心
    cv2.drawMarker(annotated, (cx, cy), color=(0, 0, 255), 
                   markerType=cv2.MARKER_CROSS, markerSize=20, thickness=2)
    
    # 4. 绘制判定标签
    label = "✓ PASS" if is_passed else "✗ FAIL"
    color = (0, 255, 0) if is_passed else (0, 0, 255)
    cv2.putText(annotated, label, (roi_x, roi_y - 10), 
                cv2.FONT_HERSHEY_SIMPLEX, 1.0, color, 2)
    
    # 5. 绘制详细信息
    info_lines = [
        f"Coverage: {coverage_ratio*100:.1f}%",
        f"Offset: ({offset_x_px:.0f}px, {offset_y_px:.0f}px)"
    ]
    for i, line in enumerate(info_lines):
        cv2.putText(annotated, line, (roi_x, roi_y + roi_h + 30 + i*25),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 255, 255), 1)
    
    return annotated
```

## 9. 常见问题与调试

### 9.1 漏检问题
**症状**：明明有泡棉，但检测为不存在


**可能原因**：
- 光照过暗，泡棉不够白
- ROI位置不准确
- 覆盖率阈值过高

**解决方案**：
1. 调整光照或降低 `gray_threshold` 阈值
2. 在前端工作台重新标定ROI
3. 降低 `coverage_threshold` 阈值（如从8%降到5%）

### 9.2 误检问题
**症状**：把背景误检为泡棉

**可能原因**：
- 背景有反光或高亮区域
- 形态学核过大，连接了背景
- 轮廓过滤不严格

**解决方案**：
1. 提高 `gray_threshold` 阈值
2. 减小 `morph_kernel_size` 或 `min_area`
3. 调整 `max_compactness` 过滤不规则区域

### 9.3 位置偏移误报
**症状**：泡棉位置正常，但判定为偏移

**可能原因**：
- ROI中心与理论位置不一致
- `max_offset_px` 阈值过严

**解决方案**：
1. 重新标定ROI中心位置
2. 放宽 `max_offset_px` 阈值（如从30px增加到50px）

### 9.4 调试建议


1. **使用前端工作台**：实时预览检测效果，快速调试参数
2. **查看结果图**：观察轮廓绘制，判断是漏检还是误检
3. **查看质量分析**：观察图像质量指标，判断是否需要调整光照
4. **逐步调整参数**：单个参数逐步调整，观察效果变化
5. **保存测试图像**：导入本地图片进行离线测试，加快调试速度

## 11. ⚠️ 算法局限性与脏污问题应对

### 11.1 当前算法类型说明

**重要提示**：当前泡棉检测模块使用的是**传统图像处理算法，不是目标检测算法**。

**算法特征**：
- **颜色特征检测**：依赖HSV/LAB色彩空间提取白色区域
- **形态学处理**：通过开运算、闭运算连接和去噪
- **轮廓分析**：基于面积、宽高比、紧凑度过滤

**优点 ✅**：
- 计算速度快（< 100ms/帧）
- 无需训练数据和GPU
- 算法逻辑可解释，易于理解
- 参数可实时调节

**缺点 ❌**：
- **对环境光照敏感**：亮度变化影响检测精度
- **对泡棉颜色变化敏感**：脏污、磨损、黄化导致漏检
- **对背景干扰敏感**：白色异物容易误检
- **泛化能力弱**：新场景需要重新调参

---

### 11.2 脏污与环境变化问题

#### 11.2.1 常见问题场景分析

| 问题场景 | 现象 | 传统算法失效原因 | 影响程度 |
|----------|------|----------------|---------|
| **泡棉脏污** | 白色变灰黄 | HSV/LAB阈值失效，V值和L值降低 | ⚠️⚠️⚠️ 严重 |
| **光照变化** | 亮度不均匀 | 固定阈值不适应，局部过暗/过亮 | ⚠️⚠️ 中等 |
| **背景干扰** | 白色标签/零件 | 无法区分泡棉与其他白色物体 | ⚠️⚠️ 中等 |
| **泡棉老化** | 颜色黄化发暗 | 白色检测阈值不匹配，饱和度增加 | ⚠️⚠️⚠️ 严重 |
| **表面反光** | 局部高光 | 过度检测，边界不准确 | ⚠️ 轻微 |
| **阴影遮挡** | 局部过暗 | 漏检暗区域泡棉 | ⚠️⚠️ 中等 |
| **灰尘积累** | 对比度下降 | 泡棉与背景分界模糊 | ⚠️⚠️ 中等 |

#### 11.2.2 当前算法的应对措施（效果有限）

虽然代码中已经实现了一些鲁棒性措施，但对严重脏污效果有限：

**1. 多策略融合检测（5种策略OR组合）**
```python
# 即使其中一种策略失效，其他策略可能仍能检测
mask_combined = cv2.bitwise_or(mask_hsv, mask_lab)
mask_combined = cv2.bitwise_or(mask_combined, mask_otsu)
mask_combined = cv2.bitwise_or(mask_combined, mask_gray)
mask_combined = cv2.bitwise_or(mask_combined, mask_adaptive)
```
**局限**：对严重脏污仍然无效，所有策略都基于颜色/亮度特征

**2. 图像质量自适应调整**
```python
# 根据亮度自动降低/提高阈值
if mean_brightness < 80:
    adjusted_cfg['white_min_v'] = base_v - 20
```
**局限**：只能应对光照变化，无法应对颜色本质变化（脏污黄化）

**3. 形态学增强连接**
```python
# 连接断裂的脏污泡棉区域
mask_combined = cv2.morphologyEx(mask_combined, cv2.MORPH_CLOSE, kernel, iterations=3)
```
**局限**：只能连接轻微断裂，严重脏污导致的大面积漏检无法修复

### 11.5 方案B：深度学习替换（根本解决）★★★★★

**推荐原因**：这是**唯一能根本解决脏污问题的方案**

#### 11.5.1 为什么深度学习能解决脏污问题？

| 特征 | 传统算法 | 深度学习 |
|------|---------|---------|
| **依赖特征** | 颜色（HSV/LAB） | 形状+纹理+上下文+颜色综合 |
| **学习能力** | 无，固定规则 | 从数据中自动学习泡棉特征 |
| **泛化能力** | 差，每个场景需调参 | 优，自动适应多种状态 |
| **脏污鲁棒性** | 差，颜色变化就失效 | 优，学会识别"脏泡棉" |

**核心原理**：深度学习不仅看颜色，还看形状、纹理、位置关系等高维特征，即使泡棉变色，只要形状和纹理没变，就能识别。

#### 11.5.2 推荐算法选择

**方案1：基于分割的方案（推荐）**

**算法**：U-Net / DeepLabV3+ / Mask R-CNN

**优势**：
- ✅ 逐像素分类，覆盖率计算精准
- ✅ 对脏污、颜色变化鲁棒
- ✅ 可以区分不同类型的缺陷

**实施步骤**：

```python
# 伪代码：基于U-Net的泡棉分割
import torch
from torchvision import transforms
from models import FoamSegmentationNet  # 自定义U-Net模型

class DeepLearningFoamInspector:
    def __init__(self, model_path):
        self.model = FoamSegmentationNet.load_from_checkpoint(model_path)
        self.model.eval()
        self.transform = transforms.Compose([
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.485, 0.456, 0.406], 
                               std=[0.229, 0.224, 0.225])
        ])
    
    def inspect(self, image, roi):
        # 1. 提取ROI
        x1, y1, x2, y2 = roi
        roi_img = image[y1:y2, x1:x2]
        
        # 2. 预处理
        input_tensor = self.transform(roi_img).unsqueeze(0)
        
        # 3. 模型推理
        with torch.no_grad():
            mask_pred = self.model(input_tensor)  # 输出：泡棉概率图
            mask_binary = (mask_pred > 0.5).cpu().numpy()[0, 0]
        
        # 4. 后处理：计算覆盖率
        foam_area = np.sum(mask_binary)
        roi_area = (x2 - x1) * (y2 - y1)
        coverage_ratio = foam_area / roi_area
        
        # 5. 判定
        is_present = coverage_ratio >= 0.08
        
        return {
            'is_present': is_present,
            'coverage_ratio': coverage_ratio,
            'mask': mask_binary,
            'confidence': float(mask_pred.max())  # 模型置信度
        }
```

```python
        self.model = YOLO(model_path)  # 加载训练好的模型
    
    def inspect(self, image, roi):
        # 1. 提取ROI
        x1, y1, x2, y2 = roi
        roi_img = image[y1:y2, x1:x2]
        
        # 2. YOLO推理
        results = self.model(roi_img, conf=0.5)  # 置信度阈值0.5
        
        # 3. 解析结果
        detections = results[0].boxes  # 检测框
        foam_boxes = [box for box in detections if box.cls == 0]  # 类别0：泡棉
        
        # 4. 判定
        is_present = len(foam_boxes) > 0
        
        if is_present:
            # 计算覆盖率
            total_foam_area = sum([
                (box.xyxy[0][2] - box.xyxy[0][0]) * 
                (box.xyxy[0][3] - box.xyxy[0][1]) 
                for box in foam_boxes
            ])
            roi_area = (x2 - x1) * (y2 - y1)
            coverage_ratio = total_foam_area / roi_area
            confidence = max([box.conf.item() for box in foam_boxes])
        else:
            coverage_ratio = 0.0
            confidence = 0.0
        
        return {
            'is_present': is_present,
            'coverage_ratio': coverage_ratio,
            'boxes': foam_boxes,
            'confidence': confidence
        }
```

### 11.6 方案C：混合方案（中期过渡）★★★★

**思路**：传统算法 + 深度学习异常检测，兼顾速度和准确性

#### 11.6.1 混合架构

```python
class HybridFoamInspector:
    def __init__(self, traditional_inspector, dl_inspector):
        self.traditional = traditional_inspector  # 传统算法（快）
        self.deep_learning = dl_inspector         # 深度学习（准）
        self.use_dl_threshold = 0.6  # 低于此置信度使用深度学习
    
    def inspect(self, image, roi):
        # 1. 传统算法初检（快速筛选）
        result_traditional = self.traditional.inspect(image, roi)
        
        # 2. 根据置信度决定是否使用深度学习
        confidence = result_traditional.get('score', 0.0)
        
        if confidence > 0.9:
            # 高置信度，直接返回传统算法结果
            result_traditional['method'] = 'traditional'
            return result_traditional
        
        elif confidence < self.use_dl_threshold:
            # 低置信度，疑似脏污或异常，使用深度学习复检
            result_dl = self.deep_learning.inspect(image, roi)
            result_dl['method'] = 'deep_learning'
            result_dl['traditional_confidence'] = confidence  # 记录传统算法置信度
            return result_dl
        
        else:
            # 中等置信度，返回传统算法结果
            result_traditional['method'] = 'traditional'
            return result_traditional
```

**优势**：
- ✅ 大部分情况用传统算法，速度快
- ✅ 疑似脏污时用深度学习，准确率高
- ✅ 成本相对较低（只需训练一个模型）

**实施步骤**：
1. 先用传统算法部署到生产环境
2. 并行采集低置信度样本（疑似脏污）
3. 针对这些样本训练深度学习模型
