# PLC 五路触发与调试规则

正常模式：DB2.DBX46.2（3D）、46.3（2D）、46.4（封箱）仅在实际读取 False→True 时执行一次。PLC 保持 True 5秒期间不重复，False 复位不执行。启动/重连先建立基线，不把首次 True 当作新触发；软件不复位这三个输入。

DB2.DBB0 产品条码、DB2.DBB24 料框码：首次非空有效码或与上次有效码不同才处理。空值及 NoRead 不清空去重记录；重连保留条码去重。A→空值→A 不重复，A→B 可处理 B。

调试模式默认关闭。开启后仅在有效信号保持期间重复：两个相机触发为 True 才拍，封箱 True 才提交；条码非空且不是 NoRead 才调用对应校验/业务。每路完成后至少间隔2秒，串行执行，不追赶积压时间点。重复调用真实 MES 查询、产品绑定、封箱；重复绑定不重复增加本地产品数量，同一料框重复查询不清空装箱统计。格式或业务校验仍然生效。

关闭调试丢弃未提交的调试任务；已开始的相机采集完成，已提交的 MES 请求使用原请求标识继续收取结果，不生成新提交。关闭后持续 True 不作为新的正常触发，须先 False 再 True。未知结果封箱保留人工核对保护。

验证：35项 Django 回归通过，涵盖三路启动高电平、保持高电平、复位、下一上升沿、两条码空值/NoRead/重连去重、调试2秒节流、真实业务层MES重复调用（网络使用测试替身）、关闭清队列、已提交MES请求恢复。

升级：退出旧版程序，备份现场数据。将旧程序的数据文件夹拖到新包的“使用原数据启动.cmd”，沿用现场数据库、配方、标定、模板及网关配置；不要用新包数据库覆盖现场数据。完整应用目录不压缩交付。现场PLC和相机验收仍需进行。
