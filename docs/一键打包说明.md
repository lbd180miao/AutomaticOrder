# 一键打包

在项目根目录双击 `package-project.cmd`（或“一键打包.cmd”）。使用本项目 `.venv` 中的 Python、PyInstaller 和已安装依赖，无需每次输入命令。

成功后控制台显示 `BUILD SUCCESS`，并打开 `delivery`。每次生成新的时间戳目录，包含：

- `AGVControl`：完整应用，自动监听 PLC，2D 持续检测，3D 由 PLC 触发；MES 通过 HTTP 转发外部电脑。
- `ExternalControl`：完整应用与 MES 网关，不自动启动 AGV 的 PLC/相机硬件控制。
- `clean-release-audit.json`：资源排除、配方/标定保留及数据库完整性检查报告。

交付整个角色文件夹，不只复制 EXE。不生成压缩包。

## 数据规则

- 不带历史点云、图片、视频、临时上传、SDK 采集示例。
- 按白名单保留必要的标准模板、界面图标和相机参数；保留数据库配方与标定。
- 构建通过 SQLite 备份生成快照，仅清理快照中的历史，原项目数据库不清理。
- 2D 实时相机不录制视频，不保存连续帧历史；每个确认 NG 的结果和时间写入运行数据目录 `foam_ng.sqlite3`。后续 OK 不删除 NG 历史，也不回写 PLC。
- 新安装包不携带开发机 NG/通信历史。升级现场软件前备份并保留现场数据目录（包括 `foam_ng.sqlite3`），使用随包“使用原数据启动.cmd”启动。
- 视频工作台的人工上传属于离线调试素材，并非实时视频录像；不随部署包交付。

## 注意

打包期间不要同时启动第二次打包或修改配方。依赖安装在项目 `.venv`，相机厂家驱动仍需安装在使用相机的现场电脑。

失败时窗口会保留错误信息；不要交付未显示成功且未通过审计的目录。历史输出不自动删除。

每次构建日志保存到 `build/package-logs`。脚本还会核对 EXE 内关键代码版本，并用隔离数据库、关闭相机的方式检查两套程序页面启动。
