## 关键技术点说明

### 1. 3D深度相机定位
- 手眼标定精度：±0.5mm
- 点云处理：基于料架刚性立柱定位
- 分层独立补偿：每层首件触发
- 三轴偏差计算：X/Y/Z实时补偿

### 2. 2D泡棉检测
- 检测对象：料架内部泡棉贴附状态
- 检测项目：漏贴、偏移、起翘、覆盖不足
- 检测模式：左右料架独立检测
- 响应速度：<2秒/次

### 3. 双机器人协同
- 空中交接握手确认
- 真空/夹持状态监测
- 安全释放机制
- 节拍并行优化

### 4. 系统集成
- MES系统配方下发
- PLC信号交互（20+信号点）
- 视觉-PLC-机器人三方通讯
- 异常报警与恢复
