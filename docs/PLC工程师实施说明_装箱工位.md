# PLC 工程师实施说明：装箱工位简版

> 本文是第一阶段跑通流程的目标时序。本次只修改文档，不据此修改程序。
> 全部点位位于 **DB2**；料框类型新增 **DB2.DBW76（Int）**，PLC 数据块需扩展到至少 78 字节。

## 1. 通讯与基本规则

- S7 TCP/IP；PLC IP：192.168.222.10；Rack / Slot：0 / 1。
- DB2 取消“优化的块访问”，编译并下载后使用。
- 上位机串行读取 PLC，每次读取结束后至少间隔 **500 ms**；不同时轮询多个工序。
- PLC 按顺序执行，一个工序结束后再发下一个工序触发。
- **触发保持为 1，直到收到完成确认；不能发送短脉冲。**
- 相机流程：PLC 等拍照完成后即可撤销触发并移动；计算结果稍后写入 DB，在实际使用前读取。
- PLC 写字节 0～47，上位机写字节 48 起的反馈区。
- 拍照完成后不用停在原位等计算，也不用等待拍照完成位再次清零才移动。

## 3. 只按这个顺序执行

**料框到位 → 3D 定位 →〔产品条码处理 → 装箱到位 → 泡棉检测〕循环 → 装箱完成上传。**

需要换层定位时，先执行当前层 3D 定位，再继续该层的产品循环。循环次数按现场泡棉配方数量执行，PLC 与上位机使用相同数量。

### 场景一：料框到位

1. PLC 写入料框码，置 `46.0=1`，保持。
2. 上位机读取料框码。目前不访问 MES，直接使用固定示例：**INN010144 → 类型代码 1**。
3. 上位机先写 `DBW76=1`、`48.6=1`，最后置 `48.5=1`。
4. PLC 看到 `48.5=1`，读取 48.6 和 DBW76；成功则置 `46.0=0`。
5. 上位机清 `48.5=0、48.6=0`。PLC 看到完成位清零，进入 3D 定位。

其他料框码本阶段按未配置处理：类型写 0、结果写 0、完成写 1，由界面提示。本阶段**不做已有绑定查询、确认清空和 MES 清空操作**。

### 场景二：3D 拍照与定位

**PLC 触发 → 等相机拍完 → PLC 可以走；补偿算好后再写 DB。**

1. 到拍照位置后，PLC 置 `46.2=1` 并保持。上位机使用“南京工厂”3D 配方采集点云。
2. 上位机接受本次请求时清 `74.5=0、49.1=0`。PLC 看到本次拍照完成位先为 0、再变为 1，才认作本次拍完，避免读取上次保留的 1。
3. **点云采集成功后立即置 `74.5=1`。PLC 随即清 `46.2=0`，可以离开拍照位置，不等补偿计算。**
4. 上位机继续计算。算好后先写六项补偿及 `49.2`，最后置 `49.1=1`。成功时缺少第二组三项则写 0；计算失败时六项写 999、49.2 写 0，并记录报警。
5. PLC 到真正需要使用补偿的步骤时，再查看 `49.1=1`，读取补偿和 49.2。若尚未算完，仅在这个步骤等待；失败或 999 不用于运动。

### 相机信号只记住两句话

- `74.5` 是 **3D 拍完，可以走**；`49.1` 是 **3D 数据写完，可以读**。
- `74.6` 是 **2D 拍完，可以走**；`74.0` 是 **2D 结果写完，可以读**。

拍照完成和结果位由上位机保留，直到接受下一次同相机请求时清除；PLC 不需要再回传“结果已读”信号。第一阶段每台相机只处理一件，上一件结果读走后再发同相机下一次请求，避免结果覆盖。

### 循环步骤 A：产品条码处理

1. PLC 写入当前产品条码，置 `22.0=1`，保持。
2. 上位机读取条码，将“料框码 + 本次产品条码”保存到本地数据库，写 `48.2=1、48.1=1`。
3. 上位机调用 MES 单件绑定接口：成功写 `48.4=1`，失败或离线写 `48.4=0`。
4. **本地保存成功即可继续装箱**：上位机先写 `49.0=1`，最后写 `48.3=1`。MES 失败不伪报成功，数据保留在本地。
5. PLC 等到 `48.1=1` 且 `48.3=1`，读取 48.2、48.4、49.0。`48.2=1` 且 `49.0=1` 时本件放行，不要求 48.4 必须为 1。
6. PLC 置 `22.0=0`；上位机清 48.1～48.4 和 49.0。PLC 等两个完成位清零后，执行本件装箱动作。

条码为空或本地保存失败：48.2、48.4、49.0 写 0，两个完成位写 1；PLC 不装箱，界面提示处理。

### 场景三 / 循环步骤 B：2D 泡棉检测

**2D 拍照约 1 秒，拍完即可走；检测结果随后写 DB。**

1. 机器人到位，PLC 置 `46.3=1` 并保持。上位机接受请求时清 `74.6=0、74.0=0`，使用“南京工厂”2D 配方拍照。
2. 图像采集成功后，上位机置 `74.6=1`。PLC 确认本次 74.6 已由 0 变为 1，清 `46.3=0`，即可移动，不等算法计算。
3. 算法算完后，上位机写 `74.1`：1=合格，0=不合格；最后写 `74.0=1`。不合格时同时置 `74.4=1`，记录报警。
4. PLC 可以先执行不依赖本次检测结果的动作；在下一件装箱放行或本框完成前，确认 `74.0=1` 并读取 74.1。NG 则停止继续装箱。

约 1 秒是采集耗时，不是“PLC 发触发后固定等 1 秒就走”。上位机每次读取间隔 500 ms，收到触发还有延迟，所以以拍照完成位为准。相机采集失败时不发“拍照成功完成”，上位机报警并锁定工位，由人工处理。

### 场景四：装箱完成上传

1. 本框循环完成后，PLC 置 `46.4=1`，保持。
2. 上位机使用本地保存的料框与产品绑定数据，调用 MES 封箱生成区位号接口。
3. MES 成功：写 `74.3=1`，保存返回的区位号；MES 失败或离线：写 `74.3=0`，本地保留本框数据。
4. 上位机最后置 `74.2=1`。
5. PLC 看到完成，记录结果，置 `46.4=0`；上位机清 `74.2=0、74.3=0`。
6. 本次交互结束。失败时显示“MES 待上传”，不显示“上传成功”。

本阶段只描述一次上传及结果反馈。自动补传、断电恢复及复杂重试策略不在本简版时序中展开。

## 4. 最简单的区别

| PLC 当前动作 | 需要等什么 |
| --- | --- |
| 离开 3D 拍照位置 | 只等 74.5：3D 拍完 |
| 使用 3D 补偿 | 等 49.1：数据已写完，再读 49.2 和六项补偿 |
| 离开 2D 拍照位置 | 只等 74.6：2D 拍完 |
| 根据泡棉结果继续装箱 | 等 74.0：结果已写完，再读 74.1 |

**拍照时保持位置，拍完就能移动；计算结果不必实时返回，算完直接写 DB。**

本版新增的 74.5 / 74.6 及调整后的信号含义是文档约定，尚未修改程序。PLC 和上位机实施时须同时采用本版含义。其他料框、条码、MES 步骤沿用本文的简单触发流程。
