## 功能概述

### 业务需求

在3D料架定位系统中，每次执行定位时需要采集深度相机的点云数据、机器人位姿、手眼标定矩阵等信息。为了支持：

- ✅ **离线调试**: 无需硬件环境，在实验室复现现场问题
- ✅ **算法优化**: 修改ROI边界或算法参数，立即重新计算结果
- ✅ **问题追溯**: 保存问题现场数据，便于分析定位失败原因
- ✅ **回归测试**: 积累测试用例，验证算法改进不引入退化
- ✅ **培训演示**: 无需真实设备即可演示系统功能

需要实现一个**离线数据包系统**，将每次定位的完整数据打包保存到文件夹，支持后续加载和重新定位。

### 核心功能

1. **保存数据包**: 执行定位后，自动将所有输入数据和结果打包保存
2. **列表数据包**: 浏览历史保存的所有数据包
3. **加载数据包**: 选择并导入特定数据包到工作台
4. **离线重新定位**: 使用加载的数据重新执行定位算法
5. **删除数据包**: 清理不需要的历史数据

```python
class OfflineDepthCameraProvider(DepthCameraProvider):
    """离线点云提供者：从加载的数据返回"""
    
    def __init__(self, loaded_data: Dict):
        self.pointcloud = loaded_data['pointcloud']
        self.metadata = loaded_data['metadata']['camera']
    
    def capture_pointcloud(self, **kwargs) -> Dict[str, Any]:
        return {
            'data': self.pointcloud,
            'width': self.metadata['width'],
            'height': self.metadata['height'],
            'frame_index': self.metadata['frame_index'],
            'confidence': 0.95,
            'raw_data_path': '',
            'result_image_path': '',
        }


class OfflineHandEyeProvider(HandEyeProvider):
    """离线手眼标定提供者：从加载的矩阵返回"""
    
    def __init__(self, matrix: np.ndarray):
        self.matrix = matrix
    
    def get_hand_eye_matrix(self, recipe_id=None) -> np.ndarray:
        return self.matrix
    
    def save_hand_eye_matrix(self, matrix: np.ndarray, recipe_id=None) -> bool:
        return True


class OfflineRobotPoseProvider(RobotPoseProvider):
    """离线机器人位姿提供者：从加载的位姿返回"""
    
    def __init__(self, pose_matrix: np.ndarray, pose_dict: Dict[str, float]):
        self.pose_matrix = pose_matrix
        self.pose_dict = pose_dict
    
    def get_robot_pose_matrix(self, layer_no, recipe_id=None) -> np.ndarray:
        return self.pose_matrix
    
    def get_robot_pose_dict(self, layer_no, recipe_id=None) -> Dict[str, float]:
        return self.pose_dict
```

### 模块3: RackPositioningService 集成

**文件路径**: `apps/vision/rack_3d/services.py`

**新增方法**:

```python
def execute_positioning_and_export(
    self,
    recipe_id: int,
    layer_no: int,
    save: bool = True,
    export_package: bool = True
) -> Dict[str, Any]:
    """
    执行定位并导出数据包
    
    Args:
        recipe_id: 配方ID
        layer_no: 层号
        save: 是否保存结果到数据库
        export_package: 是否导出数据包
    
    Returns:
        dict: 定位结果 + package_name
    """
    # 1. 执行正常定位流程
    result = self.execute_positioning(recipe_id, layer_no, save)
    
    # 2. 如果需要导出，调用 OfflineDataPackageService
    if export_package:
        from apps.vision.offline_data_service import OfflineDataPackageService
        from apps.vision.models import RackLocationRecipe
        
        recipe = RackLocationRecipe.objects.get(id=recipe_id)
        
        # 获取原始数据
        pc = self.depth_camera_provider.capture_pointcloud(
            recipe_id=recipe_id, layer_no=layer_no
        )
        T_fc = self.hand_eye_provider.get_hand_eye_matrix(recipe_id)
        T_bf = self.robot_pose_provider.get_robot_pose_matrix(layer_no, recipe_id)
        rois = self._load_rois(recipe_id, layer_no)
        
        # 创建数据包
        service = OfflineDataPackageService()
        package_info = service.create_package(
            pointcloud=pc['data'],
            hand_eye_matrix=T_fc,
            robot_pose_matrix=T_bf,
            roi_config=rois,
            recipe=recipe,
            layer_no=layer_no,
            camera_info={...},
            result=result
        )
        
        result['package_name'] = package_info['package_name']
        result['package_path'] = package_info['package_path']
    
    return result
```

### 模块4: REST API Views

**文件路径**: `apps/vision/offline_data_views.py`

**核心视图**:

```python
from django.http import JsonResponse
from django.views.decorators.http import require_http_methods
from django.views.decorators.csrf import csrf_exempt
import json

from .offline_data_service import OfflineDataPackageService


@require_http_methods(["GET"])
def list_packages(request):
    """列出所有数据包"""
    service = OfflineDataPackageService()
    packages = service.list_packages()
    return JsonResponse({'packages': packages})


@require_http_methods(["GET"])
def get_package(request, package_name):
    """获取单个数据包详情"""
    service = OfflineDataPackageService()
    package = service.load_package(package_name)
    return JsonResponse({'package': package})


@csrf_exempt
@require_http_methods(["POST"])
def reprocess_package(request, package_name):
    """重新处理数据包 (离线定位)"""
    try:
        data = json.loads(request.body)
        recipe_id = data.get('recipe_id')
        layer_no = data.get('layer_no')
        modified_roi = data.get('modified_roi')
        
        service = OfflineDataPackageService()
        result = service.reprocess_package(
            package_name, recipe_id, layer_no, modified_roi
        )
        return JsonResponse({'result': result})
    except Exception as e:
        return JsonResponse({'error': str(e)}, status=400)


@csrf_exempt
@require_http_methods(["DELETE"])
def delete_package(request, package_name):
    """删除数据包"""
    service = OfflineDataPackageService()
    success = service.delete_package(package_name)
    return JsonResponse({'success': success})
```

```javascript
                    method: 'POST',
                    headers: {'Content-Type': 'application/json'},
                    body: JSON.stringify({
                        recipe_id: recipeId,
                        layer_no: layerNo,
                        modified_roi: null  // 如果修改了ROI，传入新的ROI配置
                    })
                }
            );
            
            const data = await response.json();
            this.renderOfflineResult(data.result);
            showToast('重新定位完成', 'success');
        } catch (error) {
            console.error('重新定位失败:', error);
            showToast('重新定位失败', 'danger');

        $('#offlineOffset').text(
            `(${result.offset_x.toFixed(2)}, ${result.offset_y.toFixed(2)}, ${result.offset_z.toFixed(2)})`
        );

        const confBadge = result.confidence >= 0.8 ? 'success' : 'warning';
        $('#offlineConfidence').html(
            `<span class="badge bg-${confBadge}">${confidence}%</span>`
        );
        
        const statusBadge = result.is_success ? 'success' : 'danger';
        const statusText = result.is_success ? '定位成功' : '定位失败';
        $('#offlineStatus').html(
            `<span class="badge bg-${statusBadge}">${statusText}</span>`
        );

        const layerNo = $('#layerSelect').val();
        
        if (!recipeId || !layerNo) {

        }

        try {
            const response = await fetch('/vision/rack_3d/positioning_and_export/', {

                headers: {'Content-Type': 'application/json'},

                    recipe_id: recipeId,
                    layer_no: layerNo,
                    save: true,
                    export_package: true
                })
            });
            
            const data = await response.json();
            showToast(`数据包已保存: ${data.package_name}`, 'success');
        } catch (error) {
            console.error('保存数据包失败:', error);
            showToast('保存失败', 'danger');
        }
    },
    
    // 删除数据包
    async deletePackage() {
        if (!this.currentPackageName) return;
        
        if (!confirm(`确定要删除数据包 "${this.currentPackageName}" 吗？`)) {
            return;
        }
        
        try {
            const response = await fetch(
                `/vision/offline/packages/${this.currentPackageName}/delete/`,

            );

            if (data.success) {

            }
        } catch (error) {
            console.error('删除失败:', error);
            showToast('删除失败', 'danger');
        }
    }
};
```

```python
# 清理超过30天的旧数据包
from datetime import datetime, timedelta
import shutil

def cleanup_old_packages(days=30):
    service = OfflineDataPackageService()
    packages = service.list_packages()
    
    cutoff_date = datetime.now() - timedelta(days=days)
    
    for pkg in packages:
        created = datetime.fromisoformat(pkg['created_at'])
        if created < cutoff_date:
            service.delete_package(pkg['package_name'])
```

4. **设置定时任务** (使用 Django-cron 或系统 cron):
```python
# 每天凌晨2点清理
0 2 * * * cd /path/to/project && python manage.py cleanup_packages
```

### A. 数据包命名规范

格式: `YYYY-MM-DD_POS{position_no}_L{layer_no}_{HHMMSS}`

示例:
- `2026-07-03_POS1_L2_143052`
- `2026-07-03_POS2_L1_150230`

### B. 错误码定义

| 错误码 | 说明 |
|--------|------|
| PKG_001 | 数据包不存在 |
| PKG_002 | 数据包文件损坏 |
| PKG_003 | 元数据解析失败 |
| PKG_004 | 点云数据加载失败 |
| PKG_005 | 矩阵数据格式错误 |
| PKG_006 | ROI配置缺失 |
| PKG_007 | 磁盘空间不足 |
| PKG_008 | 权限不足 |

### C. 性能优化建议

1. **大点云压缩**: 对于超过100万点的点云，考虑使用压缩算法
2. **预览图缓存**: 生成多种尺寸的预览图，加快加载速度
3. **分页加载**: 数据包列表超过100个时使用分页
4. **异步处理**: 重新定位操作使用异步任务队列
5. **索引优化**: `index.json` 添加更多元数据减少文件IO

### D. 常见问题

**Q: 数据包占用空间太大怎么办？**
A: 
- 可以实现点云降采样保存（保存前使用 voxel_size=3.0 降采样）
- 使用压缩格式如 `.npz`：`np.savez_compressed('pointcloud.npz', data=pointcloud)`
- 定期清理超过30天的旧数据包

**Q: 如何迁移数据包到其他机器？**
A: 
- 直接复制整个 `docs/pic` 文件夹
- 确保包含 `index.json` 文件
- 新机器上会自动识别所有数据包

**Q: 离线重新定位结果与实时定位不一致？**
A: 检查以下几点：
- 配方参数是否有变化（标准坐标、偏移阈值等）
- ROI 是否被修改
- 算法参数是否更新
- 手眼标定矩阵是否变化

**Q: 数据包列表显示不全？**
A: 
- 运行 `service._rebuild_index()` 方法重建索引文件
- 检查文件夹权限
- 确认 `index.json` 格式正确

**Q: 如何兼容现有的离线测试数据？**
A:
- 现有数据（`depth_*.npy`, `image_*.png`）会继续保存在 `docs/pic` 目录
- 新数据包系统使用子文件夹组织，不会冲突
- 可使用 `import_legacy_data()` 方法将旧数据转换为数据包格式

**Q: 为什么预览图无法显示？**
A:
- 检查静态文件服务是否配置正确
- 确认 URL路由 `/offline-packages/<path>` 已添加
- 开发环境确保 `DEBUG=True`
- 生产环境配置 Nginx提供静态文件服务

**Q: 数据包可以在不同配方间共享吗？**
A:
- 数据包绑定到具体的配方和层号
- 但可以加载后重新选择配方进行定位
- 手眼矩阵和机器人位姿可能不兼容，需要注意

**Q: 如何实现定期自动备份？**
A:
```python
# 在 cron 任务中定期压缩备份
import shutil
from datetime import datetime

backup_name = f"backup_{datetime.now().strftime('%Y%m%d')}.zip"
shutil.make_archive(
    base_name=f'/backups/{backup_name}',
    format='zip',
    root_dir='docs/pic'
)
```
