# 双料框九项监听

输入仍按 DB2 读取，一次连续读取 DBB0～69：

|信号|地址|
|---|---|
|当前产品条码 STRING[20]|DBB0|
|料框码1 STRING[20]|DBB24|
|料框码2 STRING[20]|DBB46|
|3D定位触发|DBX68.3|
|泡棉检测触发|DBX68.4|
|封箱触发1|DBX68.5|
|封箱触发2|DBX68.6|
|料箱1工作中|DBX68.7|
|料箱2工作中|DBX69.0|

三个条码分别保存上次有效值，空值、空白和NoRead（不区分大小写）不覆盖有效值，也不改变料框轮次。原码恢复不重复查询MES。产品有效码变化后标记待绑定，受理一次绑定后即去重；保持原码时，即使工作信号再次上升或切换另一料箱，也不重复绑定上传。去重状态和待执行任务一起持久化，MES等待或失败不会因重复PLC上升沿再次提交。当前快照仍为空/NoRead时不使用缓存码执行绑定，保留待绑定状态，等有效码恢复并重新触发。工作中信号上升沿锁定当次产品码、对应料框码及该料框轮次，执行产品绑定及MES单件上传。两路料框码分别在有效值首次出现或变化时查询MES。空码与NoRead不提交。两路工作信号同一采样同时上升时记录报警并拒绝含糊绑定，需要复位重触发；若只有第二路新上升而第一路仍高，则明确按第二路绑定。

两路封箱上升沿分别锁定相应料框，调用MES第三接口。排队或HTTP等待期间不会改用后续扫码值；前序同料框产品上传待处理时，封箱等待。两路MES异常记录分别保存。

六路Bool均只接受实际False→True，启动/重连时先建立基线，初始True不执行。PLC约5秒后自行复位，上位机不清零输入，也不在高电平期间重复请求。旧高电平重复调试模式停用。

## 已确认的输出范围

启用九项输出：AGV 在线心跳写 DB2.DBX70.0，X1/Y1/Z1/X2/Y2/Z2 分别写 DB2.DBD76/80/84/88/92/96，料架种类1/2分别写 DB2.DBW100/102。DB缓冲区为104字节。两个料架共用XYZ，每次计算覆盖上次结果。

AGV 后台监听启动后通过独立心跳线程，每 0.5 秒翻转 DB2.DBX70.0（False→True→False 循环，完整周期 1 秒），不受旧配置的心跳间隔影响。拍照和 MES 业务期间继续翻转。PLC 不再需要周期清零，应根据电平是否持续变化判断在线；断网或进程退出后心跳停止更新。

完成位、结果位、锁定位不参与读写，不作为业务推进条件，也不出现在手动点位列表中。泡棉检测结果、MES结果在上位机保存和显示，不写入96/98等冲突位置。PLC适配器保留通用重叠校验，已启用的18项点位之间无重叠。

验证：`python manage.py test apps.workflow.tests_dual_rack --noinput`。业务集成测试使用实际PLC适配器及字节级内存PLC，验证双料框路由、九项输出、心跳每0.5秒翻转、邻位保留及输入不被覆盖。未连接现场PLC或调用真实MES。
