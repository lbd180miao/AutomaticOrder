# AGV 与外部电脑通信

MES 接口页面第三部分采用两栏布局：左侧“发送请求”，右侧“返回结果”。不显示流程图、模式卡片和手动回填表单。独立地址 `/mes/communication/` 使用同一界面。

- 选择查询料框类型、产品绑定或装箱完成接口，填写条码后发送；本次请求按唯一编号关联，右侧自动显示等待、成功、失败及业务返回值。
- 界面发送的请求由外部电脑自动调用 MES，兼容旧版本保存的手动模式，不会等待人工填写结果。PLC 业务监听的既有模式及已等待人工处理的历史请求不自动变更。
- 页面手动发起请求使用真实 HTTP/MES 通道，不触发 PLC 写入或本地生产绑定。PLC 监听任务收到结果后继续原有生产流程。
- 通信记录展示最近 100 条任务，可以搜索并逐条打开，查看请求、返回值、异常和已加载的通信过程。
- 离线时新请求进入本地持久化队列，恢复后自动发送。重复重试复用请求编号。已接收结果在离线时仍可查看。
- 三个接口依次返回料框类型、绑定成功/失败、区位号。

设备页在 2D 相机后增加“外部电脑”状态卡，复用设备卡样式，通过带认证的 HTTP 网关健康接口检测；服务无法连接时显示离线，未配置时显示未配置，不模拟在线。

网络约定：AGV WLAN `192.168.3.6`，外部电脑 WLAN `192.168.3.10`，通过边缘路由器互通。新打包配置的 AGV 网关地址为 `http://192.168.3.10:8001`。外部电脑自身仍使用 `http://127.0.0.1:8001`。已有现场部署需要相应更新 AGV 的 `agv_gateway.json`，保留原 token。外部网关监听端口 8001，路由器不应启用无线客户端隔离。

验证：33 项后端回归测试、前端交互检查通过。未连接现场设备，未重新打包。
