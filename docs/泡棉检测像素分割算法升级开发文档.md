## 1. 升级背景与目标

### 1.1 当前算法问题

**现有算法**：轮廓外接矩形定位
```python
# 当前方式：使用外接矩形
x, y, w, h = cv2.boundingRect(contour)
center_x = x + w/2
center_y = y + h/2
coverage = (w * h) / roi_area  # 矩形面积
```

**存在问题**：
- ❌ 不规则泡棉外接矩形包含大量背景区域
- ❌ 边缘缺损时矩形框依然很大，覆盖率计算不准
- ❌ 矩形中心不等于实际泡棉质心，偏移计算误差大
- ❌ 无法评估泡棉与标准模板的贴合程度

### 1.2 升级方案：像素级分割定位

**新算法核心**：使用完整像素掩码（二值掩膜）进行精准计算

```python
# 新方式：使用像素掩码
mask = detect_foam_mask(image, roi)  # 二值掩膜 (0/255)
foam_pixels = np.count_nonzero(mask)  # 实际泡棉像素数
centroid = compute_mask_centroid(mask)  # 掩码质心
iou = compute_iou(mask, standard_mask)  # 与标准模板的IoU
```

**关键改进**：
- ✅ 精确到每个像素：只计算真实泡棉区域
- ✅ 质心定位准确：基于所有有效像素的质量中心
- ✅ 覆盖率真实：实际泡棉像素数/标准泡棉像素数
- ✅ 新增IoU指标：评估泡棉贴合完整度

### 1.3 重要说明：仍是传统图像处理

**⚠️ 概念澄清**：

## 2. 算法原理详解

### 2.1 像素掩码生成（保持原有流程）

**步骤不变**：多策略白色检测 → 掩膜融合 → 形态学处理

```python
def generate_foam_mask(roi_image, cfg):
    """生成泡棉二值掩膜（0=背景, 255=泡棉）"""
    
    # === 步骤1：多策略白色检测（保持不变） ===
    hsv = cv2.cvtColor(roi_image, cv2.COLOR_BGR2HSV)
    lab = cv2.cvtColor(roi_image, cv2.COLOR_BGR2LAB)
    gray = cv2.cvtColor(roi_image, cv2.COLOR_BGR2GRAY)
    
    # 5种检测策略
    mask_hsv = cv2.inRange(hsv, (0, 0, 150), (180, 100, 255))
    mask_lab = cv2.inRange(lab[:, :, 0], 160, 255)
    _, mask_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    _, mask_fixed = cv2.threshold(gray, 170, 255, cv2.THRESH_BINARY)
    mask_adaptive = cv2.adaptiveThreshold(gray, 255, 
                                         cv2.ADAPTIVE_THRESH_GAUSSIAN_C, 
                                         cv2.THRESH_BINARY, 21, -5)
    
    # === 步骤2：掩膜融合（OR逻辑） ===
    mask = cv2.bitwise_or(mask_hsv, mask_lab)
    mask = cv2.bitwise_or(mask, mask_otsu)
    mask = cv2.bitwise_or(mask, mask_fixed)
    mask = cv2.bitwise_or(mask, mask_adaptive)
    
    # 排除绿色区域
    green_mask = cv2.inRange(hsv, (35, 40, 40), (100, 255, 255))
    mask = cv2.bitwise_and(mask, cv2.bitwise_not(green_mask))
    
    # === 步骤3：形态学处理（增强连接和去噪） ===
    kernel_close = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (11, 11))
    kernel_open = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
    
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel_close, iterations=3)
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel_open, iterations=2)
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel_close, iterations=1)
    
    return mask  # 返回二值掩膜
```

**输出**：二值掩膜 (numpy array, dtype=uint8)
- 像素值 255：泡棉区域
- 像素值 0：背景区域

### 2.2 核心改进1：基于掩码质心的精准定位


**旧方法**：轮廓外接矩形中心
```python
# ❌ 旧算法：外接矩形中心
contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
largest_contour = max(contours, key=cv2.contourArea)
x, y, w, h = cv2.boundingRect(largest_contour)
center_x = x + w / 2  # 矩形中心
center_y = y + h / 2
```

**新方法**：掩码质心（图像矩）
```python
# ✅ 新算法：掩码质心
def compute_mask_centroid(mask):
    """计算二值掩膜的质心（重心）
    
    原理：图像矩 (Image Moments)
    - M00 = 掩膜总像素数（白色像素数量）
    - M10 = 所有白色像素的x坐标之和
    - M01 = 所有白色像素的y坐标之和
    - 质心 = (M10/M00, M01/M00)
    
    Args:
        mask: 二值掩膜 (numpy array, 0或255)
    
    Returns:
        (cx, cy): 质心坐标（浮点数）
        None: 如果掩膜为空
    """
    # 计算图像矩
    moments = cv2.moments(mask)
    
    # 检查掩膜是否为空
    if moments['m00'] == 0:
        return None
    
    # 计算质心坐标
    cx = moments['m10'] / moments['m00']
    cy = moments['m01'] / moments['m00']
    
    return (cx, cy)
```

**质心 vs 外接矩形中心的差异**：

假设泡棉形状为L型（不规则）：
```
外接矩形中心（旧）：       掩码质心（新）：
┌─────────────┐           ┌─────────────┐
│█████        │           │█████        │
│█████        │           │█████  ●     │  ← 质心偏向质量集中区域
│█████  ✕     │           │█████        │
│█████        │           │█████        │
│█████████████│           │█████████████│
└─────────────┘           └─────────────┘
  ✕ = 几何中心（不准）     ● = 质量中心（准确）
```

### 2.3 核心改进2：基于掩码像素数的覆盖率计算


**旧方法**：外接矩形面积 / ROI面积
```python
# ❌ 旧算法：矩形面积比
x, y, w, h = cv2.boundingRect(contour)
rect_area = w * h  # 包含背景
roi_area = roi_width * roi_height
coverage_ratio = rect_area / roi_area  # 不准确
```

**新方法**：实际泡棉像素数 / 标准泡棉像素数
```python
# ✅ 新算法：像素级覆盖率
def compute_coverage_ratio(detected_mask, standard_mask=None, roi_area=None):
    """计算泡棉覆盖率
    
    两种计算模式：
    1. 相对标准模板：detected_pixels / standard_pixels
    2. 相对ROI面积：detected_pixels / roi_area
    
    Args:
        detected_mask: 检测到的泡棉掩膜
        standard_mask: 标准泡棉掩膜模板（可选）
        roi_area: ROI总面积（像素）
    
    Returns:
        coverage_ratio: 覆盖率（0.0-1.0+）
    """
    # 统计检测到的泡棉像素数
    detected_pixels = np.count_nonzero(detected_mask)
    
    if standard_mask is not None:
        # 模式1：相对标准模板（推荐）
        standard_pixels = np.count_nonzero(standard_mask)
        if standard_pixels == 0:
            return 0.0
        coverage_ratio = detected_pixels / standard_pixels
        # coverage_ratio > 1.0 表示检测区域超出标准区域（可能是误检）
        # coverage_ratio < 1.0 表示泡棉缺损或贴附不完整
    else:
        # 模式2：相对ROI面积（兜底方案）
        if roi_area is None or roi_area == 0:
            return 0.0
        coverage_ratio = detected_pixels / roi_area
    
    return coverage_ratio
```

**对比示例**：

泡棉实际像素数：3000像素  
外接矩形面积：5000像素（包含背景）  
标准模板像素：3200像素

```
旧算法覆盖率 = 5000 / 10000 = 50%   ← 偏大
新算法覆盖率 = 3000 / 3200 = 93.75% ← 准确
```

### 2.4 核心改进3：交并比（IoU）评估贴合完整度


**新增指标**：IoU（Intersection over Union，交并比）

```python
def compute_iou(mask1, mask2):
    """计算两个掩膜的交并比（IoU）
    
    IoU = 交集面积 / 并集面积
    
    物理含义：
    - IoU = 1.0：完美匹配
    - IoU = 0.8-1.0：贴附良好
    - IoU = 0.5-0.8：贴附偏差，位置或形状不完全匹配
    - IoU < 0.5：严重偏差或缺损
    
    Args:
        mask1: 掩膜1（检测到的泡棉）
        mask2: 掩膜2（标准模板）
    
    Returns:
        iou: 交并比（0.0-1.0）
    """
    # 确保掩膜是二值的（0或非0）
    mask1_binary = (mask1 > 0).astype(np.uint8)
    mask2_binary = (mask2 > 0).astype(np.uint8)
    
    # 计算交集：两个掩膜都为真的像素
    intersection = cv2.bitwise_and(mask1_binary, mask2_binary)
    intersection_pixels = np.count_nonzero(intersection)
    
    # 计算并集：至少一个掩膜为真的像素
    union = cv2.bitwise_or(mask1_binary, mask2_binary)
    union_pixels = np.count_nonzero(union)
    
    # 避免除零
    if union_pixels == 0:
        return 0.0
    
    iou = intersection_pixels / union_pixels
    return iou
```

**IoU可视化示例**：

```
标准模板（蓝色）   检测结果（红色）   交集（紫色）       并集（所有颜色）
██████             ██████            ██████            ██████
██████             ██████            ██████            ██████
██████             ██████            ██████            ██████
                   ██                ══                ██████

IoU = 紫色区域 / 所有颜色区域 = 0.85（良好）
```

**应用场景**：
- ✅ 判断泡棉是否贴在正确位置
- ✅ 检测泡棉边缘缺损
- ✅ 发现泡棉形变或褶皱
- ✅ 区分"位置偏移"和"形状异常"

### 2.5 核心改进4：像素偏移转物理偏移


```python
def compute_physical_offset(detected_mask, standard_mask, mm_per_pixel_x, mm_per_pixel_y):
    """计算物理偏移量（毫米）
    
    流程：
    1. 计算检测掩膜质心
    2. 计算标准掩膜质心
    3. 计算像素偏移量
    4. 转换为物理偏移量
    
    Args:
        detected_mask: 检测到的泡棉掩膜
        standard_mask: 标准泡棉掩膜
        mm_per_pixel_x: X方向像素当量（mm/pixel）
        mm_per_pixel_y: Y方向像素当量（mm/pixel）
    
    Returns:
        dict: {
            'offset_x_px': float,  # 像素偏移（正=右偏，负=左偏）
            'offset_y_px': float,  # 像素偏移（正=下偏，负=上偏）
            'offset_x_mm': float,  # 物理偏移（毫米）
            'offset_y_mm': float,  # 物理偏移（毫米）
            'offset_distance_px': float,  # 偏移距离（像素）
            'offset_distance_mm': float,  # 偏移距离（毫米）
        }
    """
    # 1. 计算检测掩膜质心
    detected_centroid = compute_mask_centroid(detected_mask)
    if detected_centroid is None:
        return None
    
    # 2. 计算标准掩膜质心
    standard_centroid = compute_mask_centroid(standard_mask)
    if standard_centroid is None:
        return None
    
    # 3. 计算像素偏移
    offset_x_px = detected_centroid[0] - standard_centroid[0]
    offset_y_px = detected_centroid[1] - standard_centroid[1]
    
    # 4. 转换为物理偏移
    offset_x_mm = offset_x_px * mm_per_pixel_x
    offset_y_mm = offset_y_px * mm_per_pixel_y
    
    # 5. 计算偏移距离（欧氏距离）
    offset_distance_px = np.sqrt(offset_x_px**2 + offset_y_px**2)
    offset_distance_mm = np.sqrt(offset_x_mm**2 + offset_y_mm**2)
    
    return {
        'offset_x_px': round(offset_x_px, 2),
        'offset_y_px': round(offset_y_px, 2),
        'offset_x_mm': round(offset_x_mm, 3),
        'offset_y_mm': round(offset_y_mm, 3),
        'offset_distance_px': round(offset_distance_px, 2),
        'offset_distance_mm': round(offset_distance_mm, 3),
    }
```

**像素当量标定**：
```python
# 标定方法：拍摄已知尺寸的标定板
# 例如：50mm的标定块在图像中占96像素
mm_per_pixel_x = 50.0 / 96.0 = 0.521 mm/pixel
mm_per_pixel_y = 50.0 / 96.0 = 0.521 mm/pixel
```

## 3. 标准模板掩膜的创建与管理

### 3.1 标准模板掩膜的作用


**标准模板掩膜（Standard Template Mask）**：理想泡棉贴附状态的像素掩膜

**用途**：
1. **计算覆盖率**：detected_pixels / standard_pixels
2. **计算IoU**：评估贴合完整度
3. **计算偏移量**：对比两个质心位置

### 3.2 创建标准模板的三种方法

#### 方法1：从合格样本中提取（推荐）

```python
def create_standard_mask_from_sample(sample_image, roi, cfg):
    """从合格样本中提取标准模板掩膜
    
    Args:
        sample_image: 合格样本图像
        roi: ROI区域 (x1, y1, x2, y2)
        cfg: 检测配置
    
    Returns:
        standard_mask: 标准模板掩膜（二值图）
    """
    # 1. 提取ROI区域
    x1, y1, x2, y2 = roi
    roi_image = sample_image[y1:y2, x1:x2]
    
    # 2. 生成掩膜（使用现有算法）
    mask = generate_foam_mask(roi_image, cfg)
    
    # 3. 可选：清理掩膜（去除噪点）
    # 找到最大连通区域
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    if contours:
        largest_contour = max(contours, key=cv2.contourArea)
        clean_mask = np.zeros_like(mask)
        cv2.drawContours(clean_mask, [largest_contour], -1, 255, -1)
        mask = clean_mask
    
    return mask
```

**操作步骤**：
1. 选择10-20张合格样本图像
2. 对每张图像生成掩膜
3. 对所有掩膜求平均，阈值化
4. 保存为标准模板

```python
def create_average_standard_mask(sample_images, roi, cfg, threshold=0.5):
    """从多个样本创建平均标准模板
    
    Args:
        sample_images: 合格样本图像列表
        roi: ROI区域
        cfg: 检测配置
        threshold: 投票阈值（0.5表示至少50%样本认为是泡棉）
    
    Returns:
        standard_mask: 标准模板掩膜
    """
    x1, y1, x2, y2 = roi
    roi_height, roi_width = y2 - y1, x2 - x1
    
    # 累加所有样本的掩膜
    accumulated = np.zeros((roi_height, roi_width), dtype=np.float32)
    
    for img in sample_images:
        roi_img = img[y1:y2, x1:x2]
        mask = generate_foam_mask(roi_img, cfg)
        accumulated += (mask / 255.0)  # 归一化到0-1
    
    # 计算平均掩膜
    avg_mask = accumulated / len(sample_images)
    
    # 阈值化：至少threshold比例的样本认为是泡棉
    standard_mask = (avg_mask >= threshold).astype(np.uint8) * 255
    
    return standard_mask
```

#### 方法2：手动绘制标注（精确）


```python
def create_standard_mask_by_annotation(roi_width, roi_height, polygon_points):
    """通过手动标注创建标准模板
    
    Args:
        roi_width: ROI宽度（像素）
        roi_height: ROI高度（像素）
        polygon_points: 多边形顶点列表 [(x1,y1), (x2,y2), ...]
    
    Returns:
        standard_mask: 标准模板掩膜
    """
    # 创建空掩膜
    mask = np.zeros((roi_height, roi_width), dtype=np.uint8)
    
    # 将多边形顶点转换为numpy数组
    points = np.array(polygon_points, dtype=np.int32)
    
    # 填充多边形
    cv2.fillPoly(mask, [points], 255)
    
    return mask
```

**使用工具**：可以使用 [LabelMe](https://github.com/wkentaro/labelme) 或前端Canvas标注

#### 方法3：基于CAD数据生成（最精确）

```python
def create_standard_mask_from_cad(roi_width, roi_height, cad_data, 
                                  mm_per_pixel_x, mm_per_pixel_y):
    """从CAD数据生成标准模板掩膜
    
    Args:
        roi_width: ROI宽度（像素）
        roi_height: ROI高度（像素）
        cad_data: CAD泡棉轮廓数据（物理坐标，单位：mm）
        mm_per_pixel_x: X方向像素当量
        mm_per_pixel_y: Y方向像素当量
    
    Returns:
        standard_mask: 标准模板掩膜
    """
    # 将物理坐标转换为像素坐标
    pixel_points = []
    for point_mm in cad_data['contour_points']:
        x_mm, y_mm = point_mm
        x_px = int(x_mm / mm_per_pixel_x)
        y_px = int(y_mm / mm_per_pixel_y)
        pixel_points.append((x_px, y_px))
    
    # 创建掩膜
    mask = np.zeros((roi_height, roi_width), dtype=np.uint8)
    points = np.array(pixel_points, dtype=np.int32)
    cv2.fillPoly(mask, [points], 255)
    
    return mask
```

### 3.3 标准模板的存储与加载

**存储格式**：PNG图像（无损）

```python
def save_standard_mask(mask, position_no, side, save_dir='media/standard_masks'):
    """保存标准模板掩膜
    
    Args:
        mask: 标准模板掩膜
        position_no: 工位编号（0, 1, 2...）
        side: 'left' 或 'right'
        save_dir: 保存目录
    """
    os.makedirs(save_dir, exist_ok=True)
    filename = f"standard_mask_pos{position_no}_{side}.png"
    filepath = os.path.join(save_dir, filename)
    cv2.imwrite(filepath, mask)
    return filepath

def load_standard_mask(position_no, side, save_dir='media/standard_masks'):
    """加载标准模板掩膜
    
    Returns:
        mask: 标准模板掩膜，如果不存在返回None
    """
    filename = f"standard_mask_pos{position_no}_{side}.png"
    filepath = os.path.join(save_dir, filename)
    
    if not os.path.exists(filepath):
        return None
    
    mask = cv2.imread(filepath, cv2.IMREAD_GRAYSCALE)
    return mask
```

## 4. 完整算法流程

### 4.1 主检测流程（升级版）


```python
def inspect_foam_with_pixel_segmentation(image, roi, standard_mask, cfg):
    """基于像素分割的泡棉检测（主函数）
    
    Args:
        image: 输入图像
        roi: ROI区域 (x1, y1, x2, y2)
        standard_mask: 标准模板掩膜（可选，如无则使用ROI面积计算）
        cfg: 检测配置字典
    
    Returns:
        dict: 完整检测结果
    """
    x1, y1, x2, y2 = roi
    roi_image = image[y1:y2, x1:x2]
    roi_height, roi_width = roi_image.shape[:2]
    roi_area = roi_height * roi_width
    
    # === 步骤1：生成检测掩膜 ===
    detected_mask = generate_foam_mask(roi_image, cfg)
    
    # === 步骤2：计算质心 ===
    detected_centroid = compute_mask_centroid(detected_mask)
    
    if detected_centroid is None:
        # 未检测到泡棉
        return {
            'is_present': False,
            'coverage_ratio': 0.0,
            'iou': 0.0,
            'offset_x_px': 0.0,
            'offset_y_px': 0.0,
            'offset_x_mm': 0.0,
            'offset_y_mm': 0.0,
            'is_passed': False,
            'reason': 'no_foam_detected',
        }
    
    # === 步骤3：计算覆盖率 ===
    if standard_mask is not None:
        # 模式1：相对标准模板
        standard_pixels = np.count_nonzero(standard_mask)
        detected_pixels = np.count_nonzero(detected_mask)
        coverage_ratio = detected_pixels / max(standard_pixels, 1)
    else:
        # 模式2：相对ROI面积
        detected_pixels = np.count_nonzero(detected_mask)
        coverage_ratio = detected_pixels / roi_area
    
    # === 步骤4：计算IoU（如果有标准模板） ===
    if standard_mask is not None:
        iou = compute_iou(detected_mask, standard_mask)
    else:
        iou = None
    
    # === 步骤5：计算偏移量 ===
    if standard_mask is not None:
        # 相对标准模板质心
        offset_result = compute_physical_offset(
            detected_mask, standard_mask,
            cfg.get('mm_per_pixel_x', 0.52),
            cfg.get('mm_per_pixel_y', 0.52)
        )
    else:
        # 相对ROI中心
        roi_center_x = roi_width / 2
        roi_center_y = roi_height / 2
        offset_x_px = detected_centroid[0] - roi_center_x
        offset_y_px = detected_centroid[1] - roi_center_y
        offset_result = {
            'offset_x_px': round(offset_x_px, 2),
            'offset_y_px': round(offset_y_px, 2),
            'offset_x_mm': round(offset_x_px * cfg.get('mm_per_pixel_x', 0.52), 3),
            'offset_y_mm': round(offset_y_px * cfg.get('mm_per_pixel_y', 0.52), 3),
        }
    
    # === 步骤6：综合判定 ===
    coverage_threshold = cfg.get('coverage_threshold', 0.85)
    iou_threshold = cfg.get('iou_threshold', 0.70)
    max_offset_mm = cfg.get('max_offset_mm', 2.0)
    
    is_present = coverage_ratio >= coverage_threshold
    is_aligned = (offset_result['offset_distance_mm'] <= max_offset_mm 
                  if 'offset_distance_mm' in offset_result else True)
    is_complete = (iou >= iou_threshold if iou is not None else True)
    
    is_passed = is_present and is_aligned and is_complete
    
    # === 返回完整结果 ===
    result = {
        'is_present': is_present,
        'is_aligned': is_aligned,
        'is_complete': is_complete,
        'is_passed': is_passed,
        'coverage_ratio': round(coverage_ratio, 4),
        'iou': round(iou, 4) if iou is not None else None,
        'detected_pixels': int(detected_pixels),
        'standard_pixels': int(standard_pixels) if standard_mask is not None else None,
        **offset_result,
        'detected_centroid': detected_centroid,
        'detected_mask': detected_mask,  # 用于可视化
    }
    
    return result
```

### 4.2 判定规则（升级版）


**三维判定体系**：

| 判定维度 | 指标 | 阈值（推荐） | 物理含义 |
|---------|------|------------|---------|
| **存在性** | coverage_ratio | ≥ 0.85 | 检测像素数/标准像素数 ≥ 85% |
| **位置性** | offset_distance_mm | ≤ 2.0mm | 质心偏移距离 ≤ 2毫米 |
| **完整性** | iou | ≥ 0.70 | 与标准模板交并比 ≥ 70% |

def compute_mask_centroid(mask):
    """计算掩膜质心（已在前面定义）"""
    moments = cv2.moments(mask)
    if moments['m00'] == 0:
        return None
    cx = moments['m10'] / moments['m00']
    cy = moments['m01'] / moments['m00']
    return (cx, cy)

def compute_iou(mask1, mask2):
    """计算IoU（已在前面定义）"""
    mask1_binary = (mask1 > 0).astype(np.uint8)
    mask2_binary = (mask2 > 0).astype(np.uint8)
    intersection = cv2.bitwise_and(mask1_binary, mask2_binary)
    union = cv2.bitwise_or(mask1_binary, mask2_binary)
    intersection_pixels = np.count_nonzero(intersection)
    union_pixels = np.count_nonzero(union)
    if union_pixels == 0:
        return 0.0
    return intersection_pixels / union_pixels

def align_mask_to_roi(mask, mask_roi, target_roi):
    """将掩膜从一个ROI对齐到另一个ROI
    
    Args:
        mask: 原始掩膜
        mask_roi: 掩膜对应的ROI (x1, y1, x2, y2)
        target_roi: 目标ROI (x1, y1, x2, y2)
    
    Returns:
        aligned_mask: 对齐后的掩膜
    """
    mx1, my1, mx2, my2 = mask_roi
    tx1, ty1, tx2, ty2 = target_roi
    
    # 创建目标尺寸的空掩膜
    target_height = ty2 - ty1
    target_width = tx2 - tx1
    aligned_mask = np.zeros((target_height, target_width), dtype=np.uint8)
    
    # 如果尺寸不同，需要缩放
    mask_height, mask_width = mask.shape[:2]
    if mask_height != target_height or mask_width != target_width:
        mask = cv2.resize(mask, (target_width, target_height), 
                         interpolation=cv2.INTER_NEAREST)
    
    aligned_mask = mask
    return aligned_mask

"""标准模板掩膜管理器"""
import os
import cv2
import numpy as np
from pathlib import Path
from django.conf import settings


class StandardMaskManager:
    """标准模板掩膜管理器"""
    
    MASK_DIR = Path(settings.MEDIA_ROOT) / 'standard_masks'
    
    def __init__(self):
        self.MASK_DIR.mkdir(parents=True, exist_ok=True)
    
    def create_from_sample(self, sample_image, roi, cfg, position_no, side):
        """从样本创建标准模板
        
        Args:
            sample_image: 合格样本图像
            roi: ROI区域
            cfg: 检测配置
            position_no: 工位编号
            side: 'left' 或 'right'
        
        Returns:
            mask: 标准模板掩膜
            filepath: 保存路径
        """
        from apps.vision.algorithms.foam_inspector import generate_foam_mask
        
        x1, y1, x2, y2 = roi
        roi_image = sample_image[y1:y2, x1:x2]
        
        # 生成掩膜
        mask = generate_foam_mask(roi_image, cfg)
        
        # 清理：只保留最大连通区域
        contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, 
                                       cv2.CHAIN_APPROX_SIMPLE)
        if contours:
            largest = max(contours, key=cv2.contourArea)
            clean_mask = np.zeros_like(mask)
            cv2.drawContours(clean_mask, [largest], -1, 255, -1)
            mask = clean_mask
        
        # 保存
        filepath = self.save_mask(mask, position_no, side)
        
        return mask, filepath
    
    def create_from_multiple_samples(self, sample_images, roi, cfg, 
                                     position_no, side, threshold=0.5):
        """从多个样本创建平均标准模板
        
        Args:
            sample_images: 样本图像列表
            roi: ROI区域
            cfg: 检测配置
            position_no: 工位编号
            side: 'left' 或 'right'
            threshold: 投票阈值（0.5表示至少50%样本认为是泡棉）
        """
        from apps.vision.algorithms.foam_inspector import generate_foam_mask
        
        x1, y1, x2, y2 = roi
        roi_height = y2 - y1
        roi_width = x2 - x1
        
        accumulated = np.zeros((roi_height, roi_width), dtype=np.float32)
        
        for img in sample_images:
            roi_img = img[y1:y2, x1:x2]
            mask = generate_foam_mask(roi_img, cfg)
            accumulated += (mask / 255.0)
        
        avg_mask = accumulated / len(sample_images)
        standard_mask = (avg_mask >= threshold).astype(np.uint8) * 255
        
        filepath = self.save_mask(standard_mask, position_no, side)
        
        return standard_mask, filepath
    
    def save_mask(self, mask, position_no, side, version=1):
        """保存掩膜到文件
        
        Args:
            mask: 掩膜数组
            position_no: 工位编号
            side: 'left' 或 'right'
            version: 版本号
        
        Returns:
            filepath: 文件路径
        """
        filename = f"standard_mask_pos{position_no}_{side}_v{version}.png"
        filepath = self.MASK_DIR / filename
        cv2.imwrite(str(filepath), mask)
        return str(filepath)

        """加载掩膜
        
        Returns:
            mask: 掩膜数组，如果不存在返回None
        """
        filename = f"standard_mask_pos{position_no}_{side}_v{version}.png"
        filepath = self.MASK_DIR / filename
        
        if not filepath.exists():
            return None
        
        mask = cv2.imread(str(filepath), cv2.IMREAD_GRAYSCALE)
        return mask
    
    def get_mask_stats(self, mask):
        """获取掩膜统计信息
        
        Returns:
            dict: {pixels, centroid_x, centroid_y, area_ratio}
        """

        centroid = compute_mask_centroid(mask)
        
        if centroid is None:
            centroid = (0.0, 0.0)
        
        return {
            'pixels': pixels,
            'centroid_x': round(centroid[0], 2),
            'centroid_y': round(centroid[1], 2),
        }

        recipe = VisionRecipe.objects.get(id=recipe_id, position_no=position_no)
        roi_config = recipe.roi_config
        threshold_config = recipe.threshold_config
        
        # 2. 提取ROI配置
        left_roi_cfg = roi_config.get('leftFoamROI', {})
        right_roi_cfg = roi_config.get('rightFoamROI', {})
        
        left_roi = (
            left_roi_cfg['x'],
            left_roi_cfg['y'],
            left_roi_cfg['x'] + left_roi_cfg['width'],
            left_roi_cfg['y'] + left_roi_cfg['height']
        )
        
        right_roi = (
            right_roi_cfg['x'],
            right_roi_cfg['y'],
            right_roi_cfg['x'] + right_roi_cfg['width'],
            right_roi_cfg['y'] + right_roi_cfg['height']
        )
        
        # 3. 加载标准模板掩膜（新增）
        mask_manager = StandardMaskManager()
        
        try:
            left_standard = StandardMaskTemplate.objects.get(
                recipe=recipe,
                side='left',
                is_active=True
            )
            left_mask = cv2.imread(left_standard.mask_file.path, cv2.IMREAD_GRAYSCALE)
        except StandardMaskTemplate.DoesNotExist:
            left_mask = None
        
        try:
            right_standard = StandardMaskTemplate.objects.get(
                recipe=recipe,
                side='right',
                is_active=True
            )
            right_mask = cv2.imread(right_standard.mask_file.path, cv2.IMREAD_GRAYSCALE)
        except StandardMaskTemplate.DoesNotExist:
            right_mask = None
        
        # 4. 检测左侧泡棉
        left_result = _detect_foam_side(
            image, 
            left_roi, 
            threshold_config,
            standard_mask=left_mask  # 传入标准模板
        )
        
        # 5. 检测右侧泡棉
        right_result = _detect_foam_side(
            image,
            right_roi,
            threshold_config,
            standard_mask=right_mask  # 传入标准模板
        )
        
        # 6. 综合判定
        is_passed = (left_result['is_present'] and 
                    left_result['is_aligned'] and 
                    left_result['is_complete'] and
                    right_result['is_present'] and 
                    right_result['is_aligned'] and
                    right_result['is_complete'])
        
        # 7. 保存结果到数据库
        from apps.vision.models import FoamInspectionResult, VisionTask
        
        task = VisionTask.objects.create(
            recipe=recipe,
            status='completed'
        )
        
        result = FoamInspectionResult.objects.create(
            task=task,
            is_passed=is_passed,
            
            # 左侧结果
            left_coverage_ratio=left_result['coverage_ratio'],
            left_iou=left_result['iou'],
            left_detected_pixels=left_result['detected_pixels'],
            left_offset_x_mm=left_result['offset_x_mm'],
            left_offset_y_mm=left_result['offset_y_mm'],
            
            # 右侧结果
            right_coverage_ratio=right_result['coverage_ratio'],
            right_iou=right_result['iou'],
            right_detected_pixels=right_result['detected_pixels'],
            right_offset_x_mm=right_result['offset_x_mm'],
            right_offset_y_mm=right_result['offset_y_mm'],
        )
        
        # 8. 生成标注图像
        annotated_image = self._annotate_foam_result(
            image, left_result, right_result
        )

# apps/vision/views.py

@csrf_exempt
def api_create_standard_mask_from_sample(request):
    """从样本创建标准模板
    
    POST /api/foam/standard-mask/create-from-sample/
    
    Body:
    {
        "recipe_id": 1,
        "side": "left",  // "left" 或 "right"
        "sample_image": "<base64_encoded_image>",
        "creation_method": "sample"
    }
    
    Returns:
    {
        "success": true,
        "template_id": 123,
        "mask_pixels": 3200,
        "centroid_x": 45.2,
        "centroid_y": 35.8,
        "mask_preview": "<base64_encoded_mask>"
    }
    """
    if request.method != 'POST':
        return JsonResponse({'error': 'Method not allowed'}, status=405)
    
    try:
        data = json.loads(request.body)
        recipe_id = data['recipe_id']
        side = data['side']
        sample_image_b64 = data['sample_image']
        
        # 解码图像
        image_data = base64.b64decode(sample_image_b64.split(',')[1])
        nparr = np.frombuffer(image_data, np.uint8)
        sample_image = cv2.imdecode(nparr, cv2.IMREAD_COLOR)
        
        # 加载配方
        recipe = VisionRecipe.objects.get(id=recipe_id)
        roi_config = recipe.roi_config
        threshold_config = recipe.threshold_config
        
        # 获取ROI
        roi_key = 'leftFoamROI' if side == 'left' else 'rightFoamROI'
        roi_cfg = roi_config[roi_key]
        roi = (
            roi_cfg['x'],
            roi_cfg['y'],
            roi_cfg['x'] + roi_cfg['width'],
            roi_cfg['y'] + roi_cfg['height']
        )
        
        # 创建标准模板
        mask_manager = StandardMaskManager()
        mask, filepath = mask_manager.create_from_sample(
            sample_image, roi, threshold_config,
            recipe.position_no, side
        )
        
        # 获取掩膜统计
        stats = mask_manager.get_mask_stats(mask)
        
        # 保存到数据库
        template = StandardMaskTemplate.objects.create(
            recipe=recipe,
            side=side,
            mask_file=filepath,
            mask_pixels=stats['pixels'],
            centroid_x=stats['centroid_x'],
            centroid_y=stats['centroid_y'],
            creation_method='sample',
            version=1,
            is_active=True
        )
        
        # 掩膜可视化（转为彩色用于预览）
        mask_colored = cv2.applyColorMap(mask, cv2.COLORMAP_JET)
        _, buffer = cv2.imencode('.png', mask_colored)
        mask_preview_b64 = base64.b64encode(buffer).decode('utf-8')
        
        return JsonResponse({
            'success': True,
            'template_id': template.id,
            'mask_pixels': stats['pixels'],
            'centroid_x': stats['centroid_x'],
            'centroid_y': stats['centroid_y'],
            'mask_preview': f"data:image/png;base64,{mask_preview_b64}"
        })
        
    except Exception as e:
        return JsonResponse({'error': str(e)}, status=500)

import unittest

from apps.vision.algorithms.foam_inspector import (

class TestPixelSegmentation(unittest.TestCase):
    
    def test_compute_mask_centroid(self):
        """测试质心计算"""
        # 创建一个简单的正方形掩膜
        mask = np.zeros((100, 100), dtype=np.uint8)
        mask[25:75, 25:75] = 255  # 50x50的正方形，中心应该在(50, 50)
        
        centroid = compute_mask_centroid(mask)
        
        self.assertIsNotNone(centroid)
        self.assertAlmostEqual(centroid[0], 50.0, delta=0.5)
        self.assertAlmostEqual(centroid[1], 50.0, delta=0.5)
    
    def test_compute_mask_centroid_empty(self):
        """测试空掩膜"""
        mask = np.zeros((100, 100), dtype=np.uint8)
        centroid = compute_mask_centroid(mask)
        self.assertIsNone(centroid)
    
    def test_compute_iou_perfect_match(self):
        """测试IoU：完美匹配"""
        mask1 = np.zeros((100, 100), dtype=np.uint8)
        mask1[25:75, 25:75] = 255
        
        mask2 = mask1.copy()
        
        iou = compute_iou(mask1, mask2)
        self.assertAlmostEqual(iou, 1.0, delta=0.01)
    
    def test_compute_iou_partial_overlap(self):
        """测试IoU：部分重叠"""
        mask1 = np.zeros((100, 100), dtype=np.uint8)
        mask1[25:75, 25:75] = 255  # 50x50，面积2500
        
        mask2 = np.zeros((100, 100), dtype=np.uint8)
        mask2[50:100, 25:75] = 255  # 50x50，偏移25像素
        
        # 交集：25x50 = 1250
        # 并集：75x50 = 3750
        # IoU = 1250 / 3750 = 0.333
        
        iou = compute_iou(mask1, mask2)
        self.assertAlmostEqual(iou, 0.333, delta=0.01)
    
    def test_compute_iou_no_overlap(self):
        """测试IoU：无重叠"""
        mask1 = np.zeros((100, 100), dtype=np.uint8)
        mask1[0:50, 0:50] = 255
        
        mask2 = np.zeros((100, 100), dtype=np.uint8)
        mask2[50:100, 50:100] = 255
        
        iou = compute_iou(mask1, mask2)
        self.assertAlmostEqual(iou, 0.0, delta=0.01)
