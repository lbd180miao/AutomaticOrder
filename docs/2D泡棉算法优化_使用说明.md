# 2D 泡棉算法优化使用说明

## 已实现

- 图像质量分析不再自动降低覆盖率验收门限。
- 每侧增加面积保持率、平移对齐后的缺损率、超出比例、四分区最大缺损率；面积比不截断到 100%。
- `separated-v2` 将完整性与原始 X/Y 偏移分开验收，并保留旧覆盖率用于对照。
- 面积过大、缺料、局部缺损、偏移等原因可同时保存在 `quality_failures`；汇总记录包含 `is_complete`、`inspection_status`、有效配置和质量算法版本。
- 白色使用阈值分割。灰色使用阴影分割（`gray-graphcut-v3`），按每侧泡棉与周围背景的对比选取种子。局部对比不足时，也可利用明显亮于背景的高光种子。处理最长边为 1024 像素，执行 3 次 GrabCut 迭代。
- 左右标准 ROI 定义标准形状与位置。调整泡棉颜色或分割参数后可直接用已有 ROI 试检。
- 配方页管理颜色、合格判定和高级参数。工作台显示当前判定参数，并用于绘制 ROI、保存参考图和试检。
- 增加只读图片回放命令，不创建生产检测记录、不发送 PLC 信号，并跳过相机服务自动启动。

## 旧配方与启用方式

没有 `decision_mode` 的旧配方仍为 `legacy`，原有覆盖率和偏移门限不变。取消低对比度时自动放宽 0.02 的行为，会使这部分图片按配方原始门限验收。新增完整性指标可用于观察，未配置的新门限不会自动强加给现场配方。

1. 在配方页按实物选择白色或灰色。算法随颜色自动切换。未标注的旧配方沿用原有分割设置。
2. “覆盖率与偏移”使用最低覆盖率和 X/Y 偏移上限。“独立完整性与偏移”需要填写面积比的上下限、最大缺损和最大超出。
3. 需要按毫米验收时，在高级参数中填写 X/Y 像素/毫米并启用毫米公差。两轴标定完成后使用毫米公差，其余情况使用像素公差。
4. 在工作台用实际合格和缺陷样本试检，核对覆盖率、完整性和偏移。

门限定义：面积比为当前面积/标准面积；缺损比例为对齐后的标准未覆盖面积/标准面积；超出比例为对齐后的检测额外面积/标准面积。比例 0.2 表示 20%。可通过 `threshold_config.max_local_missing_ratio` 额外限制四分区最大缺损比例。

原覆盖率字段和历史兼容的 `defect_type` 保留；细分原因应读取 `quality_failures`。`score` 仍是旧覆盖率评分，不是新判定的置信概率，也不能用它单独决定放行。

## 配方接口字段

`algorithm_config` 支持 `material_type`（unspecified/white/gray）、`foam_segmentation`、`segmentation_config`。白色或灰色配方按 `material_type` 决定分割方式，未标注配方读取 `foam_segmentation`。固定阈值路径使用 `segmentation_config` 中的整数 `foam_min_v` 和 `foam_max_s`，范围 0～255。

`threshold_config` 支持 `decision_mode`（legacy/separated-v2）、`min_area_ratio`、`max_area_ratio`、`max_missing_ratio`、`max_excess_ratio`、可选 `max_local_missing_ratio`。这些门限在 legacy 中也可作为额外约束，传 null 可清除可选门限。separated-v2 需要左右标准 ROI、本层搜索 ROI 和前四项完整性门限。

## 离线回放

准备 UTF-8 JSON 文件 `limits.json`，填写前述四个完整性门限，不包含 `decision_mode` 或分割参数。以下是命令形式；路径和配方 ID 按实际替换：

```powershell
python manage.py replay_foam_quality --recipe 14 --images "D:\samples\good.png" "D:\samples\missing.png" --limits "D:\samples\limits.json" --output "D:\samples\replay-report.json"
```

输出文件须使用新路径。回放读取配方的标准 ROI 和当前分割模式，比较原覆盖率判定与试验完整性门限。图像尺寸以保存的原始示教图为准。报告记录每侧指标、失败原因、耗时及判定变化。

未提供人工真值标签，因此报告不能计算误报率或漏检率。基线为原覆盖率规则，但不重现已移除的自动放宽门限。

## 验证与边界

回归覆盖对称缺料、完整泡棉平移、巨型反光、局部缺口、灰色无亮点、单侧缺失、非法门限和配方保存回滚。

位置比较使用掩膜重心差，完整性比较先对齐平移量。启用产品本体定位时，工作台需要两个产品基准区和合格样件参考图。灰色阴影分割需要可用于识别的局部对比或高光，较小的缺口受处理分辨率限制。

`INVALID` 目前用于已有的 ROI 太小、均匀饱和、缺少暗支撑等不可靠结果，不代表已建立完整的图像质量分类器。未分出泡棉仍可能来自真实缺失或分割失败，需结合原图判读。无翘边高度测量。

新分割与完整性门限需通过独立现场样本验证后启用；不能仅凭合格示教原图自检通过就替换生产判定。
