# 2D 泡棉算法优化使用说明

## 已实现

- 图像质量分析不再自动降低覆盖率验收门限。
- 每侧增加面积保持率、平移对齐后的缺损率、超出比例、四分区最大缺损率；面积比不截断到 100%。
- `separated-v2` 将完整性与原始 X/Y 偏移分开验收，并保留旧覆盖率用于对照。
- 面积过大、缺料、局部缺损、偏移等原因可同时保存在 `quality_failures`；汇总记录包含 `is_complete`、`inspection_status`、有效配置和质量算法版本。
- 灰色新增 `gray-graphcut-v3`：按左右参考区域各自与周围背景的对比生成种子，允许没有白色高光的灰色泡棉；最长边 1024 像素，3 次 GrabCut 迭代。原有两种阴影模式与固定阈值模式保留。
- 材质、分割参数变更使旧模板失效，需要重新示教；新判定模式不允许静默缩放不匹配的模板。
- 工作台增加“材质与完整性判定”配置，展示实际模板模式及完整性指标；配方保存 API 支持相同字段。
- 增加只读图片回放命令，不创建生产检测记录、不发送 PLC 信号，并跳过相机服务自动启动。

## 旧配方与启用方式

没有 `decision_mode` 的旧配方仍为 `legacy`，原有覆盖率和偏移门限不变。取消低对比度时自动放宽 0.02 的行为，会使这部分图片按配方原始门限验收。新增完整性指标可用于观察，未配置的新门限不会自动强加给现场配方。

在工作台选择配方，展开“材质与完整性判定”：

1. 根据实物指定白色或灰色。材质是配方标签，不会自动切换分割算法。
2. 白色可保留固定阈值；灰色可在独立草稿中试用“灰色局部对比分割”。切换材质或分割方式后使用合格实拍图重新示教。
3. 选择“独立完整性与偏移”时必须填写四个已验证门限：最小面积比、最大面积比、最大缺损比例、最大超出比例。没有通用生产默认值。
4. 保留并校验 X/Y 公差及像素/mm 标定。新完整性比较不会消除原始偏移判定。
5. 用实际合格和缺陷样本回放，验证通过后再发布配方。现有数据库配方未由本次代码改动自动升级。

门限定义：面积比为当前面积/标准面积；缺损比例为对齐后的标准未覆盖面积/标准面积；超出比例为对齐后的检测额外面积/标准面积。比例 0.2 表示 20%。可通过 `threshold_config.max_local_missing_ratio` 额外限制四分区最大缺损比例。

原覆盖率字段和历史兼容的 `defect_type` 保留；细分原因应读取 `quality_failures`。`score` 仍是旧覆盖率评分，不是新判定的置信概率，也不能用它单独决定放行。

## 配方接口字段

`algorithm_config` 支持 `material_type`（unspecified/white/gray）、`foam_segmentation`、`segmentation_config`。后者目前只支持整数 `foam_min_v`、`foam_max_s`，范围 0～255；它们用于固定阈值路径，不是灰色 GrabCut 的种子门限。调整它们也需要重建模板。

`threshold_config` 支持 `decision_mode`（legacy/separated-v2）、`min_area_ratio`、`max_area_ratio`、`max_missing_ratio`、`max_excess_ratio`、可选 `max_local_missing_ratio`。这些门限在 legacy 中也可作为额外约束；要取消某项可传 null。separated-v2 必须有本层搜索框和真实标准掩膜，且前四项门限不可缺省。

## 离线回放

准备 UTF-8 JSON 文件 `limits.json`，填写前述四个完整性门限，不包含 `decision_mode` 或分割参数。以下是命令形式；路径和配方 ID 按实际替换：

```powershell
python manage.py replay_foam_quality --recipe 14 --images "D:\samples\good.png" "D:\samples\missing.png" --limits "D:\samples\limits.json" --output "D:\samples\replay-report.json"
```

输出文件必须不存在。回放使用当前配方的模板和实际分割模式，比较原覆盖率判定与试验完整性门限；不会将新模式应用到旧模式的模板上。图像尺寸以模板保存的原始示教图片尺寸为准，而非 UI 预览尺寸。报告保留每侧指标、失败原因、耗时和放行结果是否变化。

未提供人工真值标签，因此报告不能计算误报率或漏检率。基线为原覆盖率规则，但不重现已移除的自动放宽门限。

## 验证与边界

新增回归覆盖对称缺料、完整泡棉平移、巨型反光、局部缺口、灰色无亮点、单侧缺失、非法门限和配方保存回滚。配方 12 和 14 的已保存示教原图均通过原规则与试验新规则回放，面积比为 1、缺损和超出为 0。这只是模板一致性检查，不等于现场准确率验证。

本轮没有实现产品本体定位、相机几何标定、旋转估计、碎片自动合并或原分辨率边缘细化；位置仍使用掩膜重心差，完整性只做平移比较。灰色新模式仍要求材质与局部背景有足够对比，没有对比时可能无检测结果；它也不保证恢复低于处理分辨率的细小缺口。

`INVALID` 目前用于已有的 ROI 太小、均匀饱和、缺少暗支撑等不可靠结果，不代表已建立完整的图像质量分类器。未分出泡棉仍可能来自真实缺失或分割失败，需结合原图判读。无翘边高度测量。

新分割与完整性门限需通过独立现场样本验证后启用；不能仅凭合格示教原图自检通过就替换生产判定。
