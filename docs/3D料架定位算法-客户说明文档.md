## 一、为什么需要3D定位？

### 传统方式的问题

**场景**: 机器人需要从料架上抓取零件

传统方式：
```
❌ 人工示教：工程师手动移动机器人到每个位置，记录坐标

   - 快速（2秒完成一层定位）
   - 精确（精度达到1-3毫米）
   - 灵活（料架移动也能自动适应）
   - 低成本（无需人工干预）
```

## 二、核心技术：三轴分离检测

### 2.1 基本思想

**类比**: 就像给房子测量三个方向的尺寸

```
┌─────────────────────────────────────┐
│        料架就像一个"房间"            │
│                                     │
│  需要知道三个方向的位置：            │
│  1. 左右位置 (X轴) - 像测量房宽     │
│  2. 前后位置 (Y轴) - 像测量房深     │
│  3. 高低位置 (Z轴) - 像测量房高     │
└─────────────────────────────────────┘
```

### 2.2 三个检测步骤

我们的算法分三步，分别检测三个方向：

#### **步骤1：检测高度（Z轴）- "找地板"**

```
目标：测量料架这一层的高度

方法：找平面
┌─────────────────────────┐
│  ■■■■■■■■■■■■■        │ ← 支撑面（平的）
│  这就像用激光水平仪找     │
│  地板一样，找一个平面     │
└─────────────────────────┘

技术：RANSAC平面拟合
- 原理：在大量测量点中，找出最平的那个面
- 结果：精确的高度数值（例如：800.1mm）
- 优势：即使有少量测量误差，也能找到正确的平面
```

#### **步骤2：检测前后位置（Y轴）- "找墙"**

```
目标：测量料架前边缘的位置

方法：找边缘
     │
     │ ← 前边缘（竖直的）
     │   就像用尺子量墙到参考点的距离
     │
     
技术：中位数计算
- 原理：在所有测量值中，取中间值
- 结果：边缘的前后位置（例如：548.3mm）
- 优势：不受个别错误测量点的影响
```

#### **步骤3：检测左右位置（X轴）- "找柱子"**

```
目标：测量料架立柱的位置

方法：找立柱
▌
▌ ← 立柱（竖直的）
▌   就像找房间角落的柱子
▌

技术：中位数计算
- 原理：在所有测量值中，取中间值
- 结果：立柱的左右位置（例如：940.2mm）
- 优势：不受个别错误测量点的影响
```

## 三、为什么用"中位数"？（非技术解释）

### 3.1 什么是中位数？

**生活中的例子**：

```
场景：测量10个学生的身高

学生身高数据：
165, 167, 166, 168, 165, 167, 166, 168, 165, 190
                                              ^^^
                                          一个特别高的

排序后：
165, 165, 165, 166, 166, 167, 167, 168, 168, 190
                         ↑
                    中位数 = 166.5cm
                    (中间两个数的平均)

平均值 = 169.2cm ❌ 被那个190cm拉高了

中位数 = 166.5cm ✅ 真实反映大部分学生的身高
```

### 3.2 在料架定位中的应用

**问题场景**：

```
相机扫描料架边缘时，会遇到：
├─ ✅ 大部分测量点：正确的（比如502mm）
├─ ❌ 少数错误点：背景墙壁（520mm）
├─ ❌ 少数错误点：反光干扰（480mm）
└─ ❌ 少数错误点：测量噪声（各种值）

如果用平均值：
(502+502+503+520+480+502+503) / 7 = 504.6mm ❌ 不准确

如果用中位数：
排序：480, 502, 502, 502, 503, 503, 520
               ↑
          中位数 = 502mm ✅ 准确！
```

### 3.3 中位数的优势

| 对比项 | 平均值 | 中位数 |
|--------|--------|--------|
| **受干扰影响** | 容易被极端值拉偏 | 不受极端值影响 |
| **适用场景** | 数据干净无噪声 | 数据有噪声（真实场景） |
| **计算复杂度** | 简单 | 简单（排序） |
| **工业应用** | 较少 | 广泛应用 |

**结论**: 中位数就像"多数派投票"，少数错误测量不会影响结果。

## 四、定位精度保障

### 4.1 置信度评估

每次定位都会给出**置信度**（类似考试分数）：

```
┌─────────────────────────────────────┐
│  置信度等级                          │
│                                     │
│  ≥ 80%  ████████░░  优秀 ✅        │
│         数据质量很好，结果可靠       │
│                                     │
│  60-80% ██████░░░░  良好 ✅        │
│         数据质量尚可，结果可用       │
│                                     │
│  < 60%  ████░░░░░░  较差 ❌        │
│         数据质量不佳，需要检查       │
└─────────────────────────────────────┘
```

### 4.2 三道质量检查

我们的系统有三道"关卡"：

```
第一关：数据质量检查
├─ 点云数量够不够？（至少要有足够的测量点）
├─ 平面拟合好不好？（支撑面要平整）
└─ 数据集中吗？（边缘和立柱测量要稳定）

第二关：置信度检查
├─ Z轴置信度 ≥ 70%？
├─ Y轴置信度 ≥ 70%？
└─ X轴置信度 ≥ 70%？

第三关：偏差范围检查
├─ X轴偏差 < 5mm？
├─ Y轴偏差 < 5mm？
└─ Z轴偏差 < 3mm？

全部通过 ✅ → 定位成功
任一不通过 ❌ → 报警提示
```

## 七、客户常见问题

### Q1: 为什么要分三个方向检测？不能一次性测量吗？

**A**: 就像量一个箱子的长宽高：

- 分别测量更精确（每个方向用最适合的方法）
- 可以单独优化（比如高度用平面拟合，边缘用中位数）
- 更容易判断哪里出问题（如果定位失败，能明确是哪个方向）

### Q2: 中位数比平均值更好吗？

**A**: 取决于场景：

- **数据干净**（实验室环境）：平均值和中位数都好
- **数据有噪声**（工业现场）：中位数更好，因为不受个别错误测量影响

工业现场必然有灰尘、反光、遮挡等干扰，所以我们用中位数。

### Q3: 定位失败了怎么办？

**A**: 系统有完整的错误处理：

1. **实时提示**：立即显示哪个轴定位失败
2. **原因分析**：告诉你是点数不足、置信度不够，还是偏差超限
3. **数据保存**：失败时的点云数据自动保存，便于后续分析
4. **重试机制**：可以调整ROI范围后重新定位

### Q4: 相机脏了会影响精度吗？

**A**: 有一定影响，但我们有保护措施：

- **置信度监控**：相机脏了会导致置信度下降，系统会报警
- **中位数鲁棒**：少量脏点不会影响中位数结果
- **定期清洁**：建议每周清洁一次相机镜头（5分钟）

### Q5: 料架变形了还能定位吗？

**A**: 可以，但有范围：

- **小变形**（±5mm以内）：完全没问题，自动适应
- **中等变形**（5-10mm）：能定位，但置信度会下降
- **大变形**（>10mm）：可能失败，需要更新配方的标准值
