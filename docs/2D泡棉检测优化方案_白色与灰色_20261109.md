# 2D 泡棉检测优化方案：白色与灰色泡棉

日期：2026-11-09。本文为改造方案，不代表相关功能已经实现。

## 1. 目标与现状

保留现有 OpenCV、配方、左右模板及 PLC 流程，优先改善误报和漏检，不立即引入深度学习。白色、灰色泡棉使用适合各自材质的分割配置，后续位置和完整性判定共用同一套定义。不同产品可有不同公差，但不能仅因分割困难而放宽产品验收标准。

依据当前代码及本地数据库检查：

| 记录 | 配方 | 对应模式 | 覆盖率门限 | X/Y 公差 |
|---|---|---|---|---|
| 608 | 12 | shadow-graphcut-fast-v2 | 30% | 4/4 mm |
| 607、606 | 14 | fixed-threshold | 40% | 8/4 mm |

这些配方均有本层搜索框；上述两套配方配置为 12 像素/mm。记录与配方不能单独证明材质颜色，需要人工检查原图并标注。白色与固定阈值、灰色与 GrabCut 的对应关系目前是合理假设，不是已验证事实。

代码入口：`apps/vision/services.py::inspect_foam`；配置：`apps/vision/recipe_utils.py::build_foam_inspection_config`；检测：`apps/vision/algorithms/foam_inspector.py`；示教：`apps/vision/algorithms/standard_mask_manager.py`。

## 2. 当前主要不足

### 2.1 用较低重合率代替完整性，可能漏检

当前本层模式覆盖率为检测掩膜与标准掩膜交集面积除以标准面积。30% 或 40% 门限可能让中心仍在标准位置、但大面积残缺的泡棉通过。这里描述的是代码允许的风险，不是已证实的现场漏检案例。不能直接提高门限解决：阴影漏分割尚未解决时，会增加合格品误报。

### 2.2 缺料与偏移相互干扰

整体平移会降低重合率；单边阴影或缺料会改变掩膜重心。当前先判缺失/不完整，再判偏移，因此真实贴偏也可能被归为 MISSING。重心差是分割形状变化与物理位移的混合结果。

### 2.3 两种材质的分割条件尚未明确管理

固定阈值默认 S≤80、V≥140，适合较亮中性材质，灰色或阴影容易漏掉。GrabCut 快速模式缩小到最长边 512 像素、迭代 3 次，依赖参考区域内部亮种子；均匀偏暗的灰色泡棉可能缺乏种子，小缺口也可能在缩小后消失。模板可以保存示教时自动切换后的算法，操作者只看配置字段可能不知道实际模式。

### 2.4 连通域匹配约束不足

每侧最终只分配一个连通域。阴影把完整泡棉分成多片时可能漏掉碎片；背景反光与泡棉相连时可能过分割。候选主要按距离和面积相似程度匹配，缺少明确的面积上限、形状及方向约束。一大片亮区可能被拆成左右候选。

### 2.5 未区分产品整体运动和贴附偏差

当前主流程没有先定位产品本体再测泡棉相对偏移。产品整体移动、视角变化、相机移动都会影响检测。固定像素/mm 对不同深度或倾角未必有效。

### 2.6 模板自检证明一致性，不能证明正确性

同一张原图自检达到 100% 覆盖率、零偏移，只能证明提取流程可重复；若初次提取的是局部亮斑，错误也会被固化。需要独立合格样件与人工轮廓核查。

### 2.7 参数和输出存在语义问题

- 图像质量自适应可能将覆盖率门限下调 0.02，改变验收标准。
- 自适应调整的 white_min_v 与本层固定分割使用的 foam_min_v 不是同一参数。
- 本层分支不会使用所有通用预处理开关，不能假定配置了降噪或 CLAHE 就已生效。
- 顶层记录与侧别记录可能保存调整前后不同门限。
- score 主要由覆盖率计算，不是识别置信度；IoU 当前不参与最终判定。
- 主流程没有独立翘边检测，不能把默认 False 解释为翘边检验合格。

## 3. 目标流程

```text
选择产品/位置/材质配方
  → 拍照及图像质量检查
  → 产品基准定位（具备稳定特征时）
  → 按白色或灰色模式分割
  → 候选筛选、受约束碎片合并、左右分配
  → 分割可靠性检查
  → 相对位置测量 + 独立完整性测量
  → 汇总 PASS / FAIL / INVALID
  → 保存指标、算法版本、原图及掩膜证据
```

初期由配方明确指定材质，不自动猜测白灰，也不同时跑两种算法后取更容易通过的结果。若同一产品左右材质不同，应允许每侧独立配置分割模式。

## 4. 具体改造

### 4.1 配方显式化与可追溯

新增或规范：material_type（white/gray）、configured_mode、effective_mode、segmentation_config、quality_limits、inspection_limits、algorithm_version、template_version、calibration_version。保留旧字段兼容读取，新增统一后的有效配置快照。

分割参数与验收门限分开管理。生产检测不得静默切换算法或放宽公差。示教允许尝试候选算法，但必须展示最终模式及提取轮廓，保存后的检测沿用该模式。旧模板迁移时不得只改标签而不检查图像。

### 4.2 白色分割

保留 HSV 固定阈值作为基线。优先固定曝光、增益、白平衡并控制反光；使用白色泡棉样本确定阈值范围。若亮度变化仍大，再评估局部背景对比和有限的亮度归一化。

形态学核尺寸按标定和目标最小缺陷尺寸确定，避免开运算删除真实细条、闭运算填掉需要检出的缺口。任何增强都必须在缺料及反光负样本上验证。

### 4.3 灰色分割

保留 GrabCut 作为第一阶段基线，但取消对灰色材质必须出现固定亮种子的单一依赖。候选方案是在产品定位后的有限搜索区域中，结合人工确认的材质颜色统计、局部对比、内部可靠区域产生种子；灰色材质与背景不可分时返回不可靠，不能直接用模板填充为前景。

采用低分辨率粗定位、高分辨率局部细化。搜索扩展按允许位移及定位误差换算成像素；轮廓细化在原分辨率完成。用最小目标缺口决定所需分辨率，不能只以速度选择 512 像素。

此方案需要验证灰色与背景的可分性，不能预先承诺仅改软件即可解决。若颜色与纹理高度相近，先改善照明或拍摄角度。

### 4.4 候选匹配与碎片合并

匹配前增加物理位移范围、面积比上下限、长宽比、主方向及边界接触检查。候选筛选范围须比合格公差宽，确保超差泡棉仍能被检测并报告偏移。

允许空间距离近、颜色接近、方向一致的片段组成候选；合并须保留真实间隙，不得通过大范围填充把缺料补齐。对跨越左右的大亮区，拆分后仍检查面积、形状和超出标准的比例。

记录候选第一、第二名差距；匹配不明确或结果异常时输出 INVALID。分割可靠性不命名为统计置信概率，除非经过专门校准。

### 4.5 独立测量位置与完整性

先定位产品上的孔位、边缘等非泡棉特征，补偿产品整体平移/旋转。没有可靠产品基准时，不进行盲目补偿；记录定位失败或按经过验证的固定工装模式运行。

在产品坐标下，用受约束轮廓匹配估计泡棉位移，记录 X/Y 和必要时的角度；保留重心偏移用于诊断。拟合失败或残差过大时，不能把输出位移当作可靠测量。

为检查完整性，仅将检测掩膜按已估计的有限平移/旋转对齐标准；不得自由缩放或非刚性变形以拟合缺损。原始位移仍独立验收。

建议指标（D 为检测掩膜，T 为标准掩膜，D' 为仅供完整性比较的对齐结果）：

| 指标 | 定义 | 用途 |
|---|---|---|
| 原位置覆盖率 | area(D∩T)/area(T) | 保留为装配位置覆盖指标 |
| 面积保持率 | area(D)/area(T)，不截断到 1 | 识别整体不足或异常膨胀 |
| 对齐后缺损率 | area(T−D')/area(T) | 检查完整性 |
| 对齐后超出比例 | area(D'−T)/area(T) | 识别反光粘连和尺寸异常 |
| 局部缺口 | 关键分区缺损、最大缺损面积/长度 | 防止总面积掩盖局部缺陷 |
| 相对位移 | 产品坐标中的 ΔX、ΔY、可选角度 | 判断贴偏 |

给边缘测量误差设置经样本验证的容差带，容差带不能大到隐藏最小目标缺陷。上述门限均由质量要求与独立样本确定，不在本文凭空指定。

### 4.6 结果语义与 PLC 兼容

内部结果建议：PASS（测量有效且全部合格）、FAIL（测量有效但质量不合格）、INVALID（图像、定位、模板或分割不可靠）。缺陷支持多标签：missing、incomplete、misaligned、excess_area 等，避免只保留优先级最高的一项。

保持现有 PLC 布尔结果兼容：仅 PASS 写通过；FAIL 和 INVALID 均不写通过，界面与记录明确区分原因。完成位与结果位仍沿用既有握手，不能因改算法改变复位语义。INVALID 是否允许自动重拍另行由节拍和现场流程确定，不能循环拍照直到碰到一次 OK。

图像质量差不自动放宽验收门限。有效配置应只有一份，左右与顶层记录从同一份快照生成。翘边字段展示“未检测”，如为实际验收要求，应单独评估侧视、结构光或其他可观察手段。

### 4.7 模板管理

保存合格原图、左右掩膜、算法参数、有效模式、图像尺寸、ROI、产品/材质标识及版本。检查模板掩膜与人工区域的面积、形状及泄漏情况。保留原图自检，新增独立拍摄合格图的重复性验证。

多张合格图用于确定允许变化范围；不能简单对掩膜取并集或交集作为新标准，否则可能扩大背景或缩小应检区域。分割参数、材质、几何配置改变后需验证模板兼容性，必要时重新示教。尺寸不匹配不得仅靠无提示 resize 掩盖几何不一致。

## 5. 实施顺序与交付物

### 阶段 A：建立基线，不改变现场判定

1. 人工核实配方 12/14 的白灰对应关系及记录原图。
2. 收集并标注真实样本，建立只读离线回放工具。
3. 保存当前算法分割掩膜、实际门限、左右指标和耗时；建立白/灰分组基线。
4. 明确最小应检缺陷、公差、节拍及允许误报/漏检水平。

交付：数据清单、标注规范、基线报告、可重复回放命令。

### 阶段 B：优先修正判定与配置

1. 显式材质和有效算法模式，统一配置快照。
2. 移除基于画质静默降低验收门限的行为，增加 INVALID 原因。
3. 增加候选面积上限、超出比例、边界及匹配歧义检查。
4. 分离存在、完整性与位置，保持原指标供新旧对比。

交付：可切换的新算法版本及逐条新旧结果对比；新门限尚未验证前不替换生产版本。

### 阶段 C：改善分割与测量

1. 分别优化白色阈值和灰色种子策略。
2. 增加受约束碎片组合与原分辨率边缘细化。
3. 有条件时加入产品定位，按位置/高度校验像素标定。
4. 完善多样件模板验证。

交付：独立验证集结果、误判案例归因、性能报告。

### 阶段 D：现场验证与切换

先离线回放，再在不改变 PLC 结果的旁路模式比较新旧结果；逐项复核不一致样本。通过现场验收后按材质/配方切换，保留旧版本和模板以便回退。新旧模板与算法版本必须配套，不能交叉使用。

## 6. 数据与验收

白色、灰色分别收集：正常件、光照变化、单侧/双侧缺失、中心/边缘缺料、断裂、允许范围内和超限偏移、反光粘连、产品整体移动、失焦及标定异常。缺陷尺寸应覆盖质量门限附近，不能只有明显大缺陷。

人工标签包含材质、左右真值、缺陷类别、必要的轮廓及实际位移。按工件和采集批次划分调参集与独立验证集；同一工件的相邻帧不能分散到两组。合成平移/光照图可用于回归，但不能替代现场缺陷样本。

分别报告：

- 合格品误报率；缺陷品漏检率；INVALID 比例，三者分开，不通过把错误移入 INVALID 美化结果。
- 按白/灰、配方、缺陷类别分别统计，并提供样本数与不确定性。
- 同件重复拍摄的位移和完整性波动；与实测位移的误差。
- 算法和端到端拍照流程的 P50/P95 耗时。
- 所有新旧不一致样本的原图、掩膜及判定原因。

验收目标须在看最终验证结果之前明确。验证集中零漏检不代表真实漏检概率为零，样本不足时不得声称达到极低漏检率。切换条件应同时满足漏检要求、误报要求、INVALID 上限及现场节拍。

## 7. 必要回归场景

保留现有模板自检、左右连通域拆分、阴影恢复和缺失测试，并新增：

1. 对称缺掉大部分泡棉、重心不变，必须按完整性失败。
2. 完整泡棉在公差内平移，不得误报缺料；公差外必须报告偏移。
3. 单侧阴影改变分割重心，不得无条件当作可靠位移。
4. 灰色泡棉无亮点时，验证新种子策略或返回明确 INVALID。
5. 大面积反光覆盖两侧，不得仅靠拆成两块就通过。
6. 真实缺口在缩放和形态学操作后仍满足可检测要求。
7. 产品整体移动补偿与泡棉相对产品贴偏能被区分。
8. 模板、材质、算法参数或分辨率不兼容时阻止误用。
9. FAIL/INVALID 均不得向 PLC 输出通过；完成与复位协议不变。

## 8. 暂不采用的捷径

不持续下调覆盖率掩盖分割问题；不把手绘模板直接填成检测结果；不以两种算法中任意一个通过作为最终通过；不以提高 IoU 门限替代位置与完整性解耦；不将单张模板自检当作现场准确率验证。

若在稳定成像后，灰色材质与背景仍不可可靠分离，再比较学习式分割的收益。即使使用学习模型，仍保留产品定位、物理公差、完整性规则、版本管理和独立验证。
