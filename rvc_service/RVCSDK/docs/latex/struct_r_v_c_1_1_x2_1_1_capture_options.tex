{\footnotesize\ttfamily double R\+V\+C\+::\+X2\+::\+Capture\+Options\+::line\+\_\+scanner\+\_\+confidence}



Line scanner confidence threshold for point cloud filtering. 

Sets the minimum confidence level for line scanner data points \mbox{[}0,1\mbox{]}
\begin{DoxyItemize}
\item Value 0\+: disables this filtering function
\item Values $>$0\+: points with confidence below this value are removed and fixed when possible
\end{DoxyItemize}

How it works\+:
\begin{DoxyItemize}
\item Higher values\+: more points removed (cleaner data)
\item Lower values\+: more points kept (may include noise)
\item Removes noise that clustering filters cannot remove
\item Default 0.\+72 works well for most scenarios within the default working range
\end{DoxyItemize}

Adjustment suggestions\+:
\begin{DoxyItemize}
\item 0.\+72 is optimal for most scenarios within the default working range
\item For extended ranges (e.\+g., scanning distant objects), consider lowering this value
\end{DoxyItemize}
