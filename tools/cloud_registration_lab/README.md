# 料架点云配准实验室

独立桌面脚本，不导入 Django 或业务代码，不读写数据库，不调用相机、机器人或 PLC。
模板的去噪、裁剪和人工选点在 CloudCompare 完成，本工具负责导入、保存模板和测试配准。

## 启动

双击同目录 `launch.bat`，使用项目现有 `.venv`，不需要安装新依赖。
演示模式：`launch.bat --demo`，然后点击“开始配准”。演示数据为内存合成数据，不是现场结果。

如果单独复制此文件夹到其他电脑，需要 Python 3.11、图形桌面和 OpenGL 支持：

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 使用步骤

### 历史 NPY 转换为 CloudCompare 可读的 PLY

在窗口顶部点击 **“历史点云 NPY → PLY”**，选择历史点云文件（例如 `pointcloud.npy`），再选择 PLY 保存位置。
无需先导入模板或运行配准，转换不会更换当前已导入的模板、测试点云或配准结果。

- 默认 **保持原坐标（仅转格式）**，不改变坐标单位。若输入坐标以米计且需要毫米，可先选择 **米 → 毫米（坐标 ×1000）**。
- 支持 `N×3` 和相机历史记录常用的 `H×W×3` 数组。去除 NaN、Inf 和 `(0,0,0)` 无效点，不做降采样、平滑或去重，保留其他原始测量点。
- 原 NPY 文件保留，输出为二进制 XYZ PLY；PLY 不保留组织化像素索引、图像和相机元数据，也不自带可靠的单位标记，后续导入时请选择实际单位。
- 不要选择标定矩阵或像素索引等非点云 NPY 文件。无有效点或数组形状错误时会报错。
- 输出已存在时会确认覆盖。转换完成后会显示路径、保留点数与无效点数。

### 模板导入和配准

1. 在 CloudCompare 中清理模板，保留可靠的料架结构，导出 **PLY（推荐）或 PCD**。
   不支持 CloudCompare BIN 工程文件。若使用 Global Shift，模板与测试点云必须按相同规则导出坐标，不能各自施加不同的未知偏移。
2. 在导入按钮旁选择文件真实单位 **mm 或 m**，再导入模板。导入后显示点数及 XYZ 尺寸，用实物尺寸核对单位。
   更改下拉选项只影响下一次导入，不会重新缩放已加载的数据。任意坐标系均可，不会删除 Z 为负的合法点。
3. 可点击“将当前模板另存为 PLY（毫米）”。这个操作保存输入清理后的模板，不进行额外平滑，也不修改输入文件。
4. 导入测试点云。支持 PLY、PCD、NPY（N×3 或 H×W×3）、XYZ、TXT、ASC、CSV、PTS、XYZN、XYZRGB。
   TXT/ASC/XYZ 是无表头的空白分隔文本，CSV 是无表头的逗号分隔文本，前三列必须为 XYZ；复杂文本请在 CloudCompare 转为 PLY。
   NPY 不允许 pickle 对象；去除非有限点、全零无效点及重复点。其他格式保留合法原点。
5. 选择模式并“开始配准”：
   - **局部配准**：模板和测试点云原始位置接近，适合同一拍照位置附近的测试。
   - **全局搜索 + 局部精配准**：位置或方向差异较大。FPFH + RANSAC 初始化，再进行 ICP；全局搜索不保证找到全局最优解，重复料架结构仍可能错配。
6. 查看叠加结果：灰色为测试点云、橙色为变换后的模板，橙色包围框表示模板所在范围。可切换配准前、配准后、误差着色和单独显示。
   鼠标左键旋转、滚轮缩放、Ctrl + 左键平移；“聚焦模板”便于检查局部接缝。
7. 导出结果会生成 `名称.json` 和 `名称_aligned.ply`。PLY 是**毫米单位、测试点云坐标系**的完整模板，可重新导入 CloudCompare 检查。
   已存在文件会请求覆盖确认；不允许覆盖当前导入文件。

## 指标解释

### 算法选择

界面“配准设置”顶部可切换：

- **算法 1：FPFH / 局部 ICP**：保留原算法，下面的局部/全局模式继续有效。
- **算法 2：PPF 表面匹配 + ICP**：计算 XYZ 和表面法线，OpenCV PPF 建模并对测试场景投票生成位姿候选，再对每个候选执行现有 ICP 和统一质量评估。
  该模式自动进行全局搜索，局部/全局下拉框禁用；“搜索次数 / 精修上限”表示最多精修多少个按票数排序的 PPF 候选（不是重复运行 PPF 的次数）。

两种算法共用候选数量、覆盖率、RMSE、P95、结构约束和位姿去重规则。算法 2 额外显示 **PPF 投票数**；票数不是概率，也不能与算法 1 的覆盖率直接对比。
候选列表、JSON 和 CSV 会记录实际计算使用的算法，切换算法下拉框不会更改已经计算出的结果，需再次点击“开始配准”。

算法 2 将模板粗采样至最多 1500 点、场景至最多 5000 点以控制 PPF 成本，使用模型直径相关采样尺度；实际采样尺度及参数记入 JSON。
PPF 的粗采样不改变最终 ICP 评分的采样尺度。输入模板的法线目前统一重算，**朝坐标原点（相机位置）定向**。
因此模板和测试点云应保留原相机坐标，适用于当前单视角、相近拍摄方向的料架数据；在 CloudCompare 中不要分别居中或旋转坐标。
这版尚未针对任意视角的完整 CAD 模型或多视角融合模型处理法线方向，也没有把 PPF 的内部训练对象持久化；每次运行会重新建模。

PPF 在独立子进程运行，原生崩溃会显示错误而非直接结束主窗口；搜索超过 180 秒会停止并报错。大量背景和重复结构仍可能产生错误候选。
本机已安装依赖至工具自己的 `.ppf_runtime`，不替换业务环境的 OpenCV。复制源码到其他电脑时，可运行 `install_ppf.bat` 安装；此安装器使用项目 `.venv`，仅向工具目录写入扩展包。
PPF 依赖固定为 `opencv-contrib-python-headless==4.13.0.92`；当前已验证的环境为 Python 3.12 + NumPy 2.4.6 + Open3D 0.19.0。

接口参考：[OpenCV PPF3DDetector](https://docs.opencv.org/4.13.0/db/d25/classcv_1_1ppf__match__3d_1_1PPF3DDetector.html)。

### 多候选搜索与人工筛选

“保留候选数量”可设为 **1–10**（默认 5）；“搜索次数”可设为保留数量至 **60**（默认 15）。
这是返回候选的上限，不是强制检测出的料架数量。多次搜索收敛到同一位姿时会合并，实际可能只返回 1 个或没有候选。
每次搜索结束后按覆盖率从高到低、同覆盖率下 RMSE 从低到高排序，仅保留前 N 个。

- 全局模式用不同随机初值搜索，并在获得足够覆盖率时暂时屏蔽已找到位置，尝试寻找其他位置。
  屏蔽只用于全局初值搜索，所有候选的精配准、评分和误差着色仍使用同一份完整测试点云。
- 局部模式以原始位置及附近随机扰动启动，适合比较附近的不同收敛解，不能替代全场景搜索。
- 合并判据是模板中心距离小于 `max(2×体素, 对应点距离)` 且相对旋转小于 3 度。
- 对应点不足 10 的结果不作为候选；其他未通过阈值的结果仍展示为“需复核”，方便人工筛选。
- 在结果下拉框选择候选编号，即可切换其模板位置、分数、RMSE、P95、结构约束比和误差着色。
- 导出生成全部候选的 **JSON 和 CSV 指标表**，以及**当前选中候选**对应的 `_aligned.ply`。
  CSV 为带 BOM 的 UTF-8，可用 Excel 筛选比较。JSON 记录所有变换矩阵、搜索次数、失败原因与当前选中编号。

候选代表位姿假设：可能是不同实体，也可能是同一实体的不同对齐方式。搜索不是穷举，不保证找全；高分不能排除重复结构错配。
搜索次数越多，耗时越长。建议先用 5 个候选、15 次搜索，全局模式开始测试。

- **匹配分数 / 模板覆盖率**：模板均匀采样点中，距测试点云不超过“对应点距离”的比例 × 100。不是定位正确概率。
- **RMSE**：有效对应点的均方根距离，单位 mm。无对应点时显示“无对应点”，不会显示为零误差成功。
- **全部模板点 P95**：全部模板采样点最近邻距离的 95 分位，包含未匹配部分，帮助发现局部遮挡或错位。
- **结构约束比**：经空间尺度归一化的点到面信息矩阵最小/最大特征值比。低于 1e-4 标为需复核；属于实验性几何退化提示，不是经过现场标定的置信度。
- **模板中心 XYZ**：模板原始点均值经过配准变换后在测试点云中的坐标，不是机器人机械定位点。
- **旋转角**：模板到测试点云刚体变换的整体轴角大小，不是单独绕 Z 的角度。
- JSON 中 4×4 矩阵 `transform_template_to_scene_mm` 满足 `p_scene = R @ p_template + t`，两边均为毫米；记录输入路径、原始单位、采样参数、质量判定及耗时。

默认实验阈值：采样体素 2 mm、对应点距离 5 mm、覆盖率下限 65%、RMSE 上限 2 mm。
它们只用于初次试验，不代表工艺允许误差。增大对应点距离会人为提高覆盖率，比较模板时应保持参数和测试数据相同。

## 实现和限制

模板仅做有效值清理、去重和均匀采样。测试点云可选统计离群点过滤。
配准使用多尺度点到点 ICP，最后使用 Huber 鲁棒点到面 ICP；质量与误差着色使用相同的采样点云和筛选后目标。
最终 PLY 保留完整输入模板点数，显示时最多约 25 万点/云以保持交互速度，显示抽样不改变配准统计。
下采样后超过 60 万点会提示裁剪或增大体素，不会静默使用更稀疏的参数。

仅有平面、长直杆、周期性横梁、遮挡严重或背景占比很高时可能失败或高分错配。
“指标通过”仍需目视确认，不代表位置唯一或机器人可直接使用。此脚本的全局搜索和评分流程与生产代码不完全相同。
运行时在后台计算，可操作视角；计算期间禁止更换数据和关闭窗口，完成后可关闭。

运行合成验证：

```powershell
..\..\.venv\Scripts\python.exe -m unittest discover -s . -p test_registration.py -v
```

算法参考：[Open3D 全局配准](https://www.open3d.org/docs/release/tutorial/pipelines/global_registration.html)。
